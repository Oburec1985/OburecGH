# HTML-презентация Rlnx

Откройте `index.html` в браузере. Презентация работает без установки и без
доступа в Интернет; изображения находятся в каталоге `assets`.

- прокрутка, `↓`, `PageDown` или пробел — следующий экран;
- `↑` или `PageUp` — предыдущий экран;
- `Home` / `End` — начало / конец;
- печать из браузера сохраняет каждый экран как отдельную страницу PDF.

Для передачи презентации копируйте весь каталог либо используйте архив
`Rlnx-html-presentation.zip` из родительского каталога.
