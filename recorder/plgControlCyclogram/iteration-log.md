## 2026-10-15 — разделены окружения Delphi 2010 и Delphi 11

**Запрос:** Устранить пересечение зависимостей двух IDE после перезапуска.
**Сделано:** В пользовательских Environment Variables BDS 7.0 и BDS 22.0 заданы отдельные PATH без каталогов другой версии. Системный PATH сохранён; резервные экспорты реестра находятся в рабочей папке текущего чата. В проектах dcl_own, GlPackage, ComponentsLib, RC_lib явно заданы выходы BPL/DCP Delphi 2010.
**Проверка:** Поиск dcl_own.bpl в окружении 2010 указывает на RAD Studio/7.0/Bpl; в окружении 11 — на D:/works/delphi11/Bpl. Все четыре пакета полностью пересобраны Delphi 2010 без ошибок; выходные BPL ненулевого размера.
**Статус:** Настройки и сборка готовы; загрузка пакетов в IDE после полного перезапуска ещё не проверена.

Правило: при параллельной установке Delphi 2010/11 исключать каталоги другой версии из PATH каждой IDE и явно задавать выходы BPL/DCP; проверять разрешение одноимённых пакетов отдельно для каждого окружения.
