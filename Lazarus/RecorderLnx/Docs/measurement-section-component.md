# Компонент мнемосхемы "Измерительное сечение"

## Назначение

Компонент "Измерительное сечение" размещается на пользовательской мнемосхеме как
прямоугольная область с редактируемой подписью. В режиме просмотра щелчок по
области открывает отдельное перемещаемое окно с таблицей текущих измерений по
точкам сечения. Окно должно быть `OnTop`, чтобы оператор мог держать таблицу
поверх мнемосхемы и закрыть ее независимо от основного окна.

## Данные строки

Одна строка таблицы соответствует одной измерительной точке/тензорозетке.

- `N точки` - пользовательский номер точки в сечении.
- `e1`, `e2`, `e3` - измерительные каналы деформации, отображаются в мкстрн.
- `t` - канал температуры/термокомпенсации в точке.
- `sigma1`, `sigma2` - расчетные главные напряжения, МПа.
- `Угол` - расчетный угол главного направления, градусы.

Для каждой роли хранится привязка к тегу RecorderLnx как пара `TagId/TagName`.
В runtime сначала используется `TagId`, имя служит fallback после импорта или
переименования.

## Настройки компонента

Компонент хранит:

- подпись области;
- список строк измерительных точек;
- тип розетки: 2-компонентная или 3-компонентная;
- положение/ориентацию розетки в градусах;
- общие свойства материала: модуль Юнга `E`, коэффициент Пуассона `nu`;
- параметры температурной поправки: опорная температура и коэффициент
  температурной деформации.

Первая реализация считает напряжения по текущим значениям тегов. Формулы не
должны выполняться в обработчиках сбора данных и не должны публиковать новые
теги; это только отображение.

## Расчет

Для 3-компонентной прямоугольной розетки используются значения `e1/e2/e3`,
соответствующие направлениям 0/45/90 градусов плюс пользовательский угол
установки. Главные деформации:

```text
avg = (e1 + e3) / 2
diff = (e1 - e3) / 2
gamma = 2 * e2 - e1 - e3
root = sqrt(diff^2 + (gamma / 2)^2)
eps1 = avg + root
eps2 = avg - root
angle = 0.5 * atan2(gamma, e1 - e3) + position
```

Напряжения при плоском напряженном состоянии:

```text
sigma1 = E / (1 - nu^2) * (eps1 + nu * eps2) * 1e-6
sigma2 = E / (1 - nu^2) * (eps2 + nu * eps1) * 1e-6
```

`E` задается в МПа, входные деформации в мкстрн. Если включена температурная
поправка и задан канал `t`, из деформаций вычитается
`alpha * (t - tref)`.

Для 2-компонентной розетки первая версия показывает `e1/e2` и рассчитывает
`sigma1/sigma2` как одноосные приближения `E * e * 1e-6`; отсутствующие каналы
отображаются прочерком.

## Import/export ODS

Настройки сечения экспортируются в таблицу LibreOffice/OpenOffice (`.ods`) с
совместимостью с таблицей импорта/экспорта каналов. Файл может содержать
пользовательские дополнительные колонки; RecorderLnx работает с колонками по
именам заголовков, а не по фиксированным номерам.

Обязательные для сечения колонки:

- `Имя канала`;
- `Сечение`;
- `N точки`;
- `Роль`;
- `Тип розетки`;
- `Расположение`;
- `Описание канала`;
- `Адрес канала`;
- `Источник`;
- `Тип канала`;
- `ID канала`;
- `Ед. изм.`;
- `Частота опроса`;
- `Запись SQL`;
- `Группа`.

`Роль` принимает значения `e1`, `e2`, `e3`, `t` либо совместимые алиасы
`x`, `y`, `z`. При импорте строка привязывается к существующему тегу по
`ID канала`, затем по паре `Источник + Адрес канала`, затем по `Имя канала`.
Если тег не найден, строка пропускается с предупреждением.

Если пользователь доработал таблицу своими колонками, экспорт обновляет только
известные колонки и не удаляет остальные данные.

## UI

В редакторе мнемосхемы компонент добавляется отдельной кнопкой.

Правая кнопка мыши по компоненту в режиме редактирования открывает форму
настроек. Форма настройки содержит общие параметры сечения и таблицу строк,
где для каждой точки выбираются теги `e1/e2/e3/t`.

В режиме просмотра щелчок по области открывает/активирует окно таблицы. Окно
не блокирует RecorderLnx, обновляется по обычному UI-периоду и не выполняет
поиск тегов по строке на каждом paint: ссылки на теги разрешаются и кэшируются
в контроле, повторное разрешение выполняется только при смене конфигурации.

## Приемка

- компонент добавляется на пользовательскую мнемосхему и сохраняется в проект;
- после перезапуска подпись, строки, материал и привязки тегов восстановлены;
- щелчок по компоненту в просмотре открывает `OnTop` таблицу;
- значения `e1/e2/e3/t` берутся из текущих тегов, отсутствующие каналы
  отображаются прочерком;
- `sigma1/sigma2/угол` пересчитываются при изменении входных тегов;
- import/export ODS находит рабочие колонки по заголовкам и сохраняет
  пользовательские дополнительные колонки.
