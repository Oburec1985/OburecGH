# Редактор формуляров

## Размещение новых компонентов

Редактор запоминает последний щелчок левой кнопкой по активной странице.
Новый визуальный компонент любого типа размещается центром около этой точки.
Учитывается щелчок как по свободному месту страницы, так и по существующему
компоненту; координата всегда переводится в систему координат страницы.
Координаты ограничиваются размерами страницы. До первого щелчка используется
безопасная начальная позиция `16,16`.

Кнопка добавления включает ожидающий инструмент вставки. Окончательные
координаты нового компонента назначает следующий щелчок по странице, а не
щелчок по кнопке панели инструментов.

## Живое изменение размера

Быстрый путь `RenderLive` не пересоздаёт визуальные контролы. При изменении
размера контейнера растровый дочерний контрол должен получить новый `Bounds`
и `Invalidate`; иначе открывшаяся часть компонента останется фоном контейнера.

Рамки выделения нельзя класть поверх растрового компонента как прозрачный
`TShape`: на некоторых LCL-widgetset его внутренняя область закрашивается фоном
родителя. Для `Image` отдельные `TShape`-рамки вообще не создаются: компонент
рисует собственный контур, а редактор добавляет только ручки изменения размера.

При выходе из режима редактирования курсор сбрасывается у полотна, контейнера,
дочернего визуального контрола и графика. Сохранённый resize-курсор не должен
попадать в рабочий режим.

Панели компонентов и служебные панели редактора нельзя различать только по
`Tag`: номера операций ресайза пересекаются с индексами компонентов. Любой
проход по компонентным контейнерам обязан исключать панели с
`Hint='Resize selection'`; иначе ручка растягивается поверх постороннего
компонента и создаёт ложное взаимное влияние элементов.
