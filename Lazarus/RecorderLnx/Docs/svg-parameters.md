# Параметры SVG в компоненте «Картинка»

RecorderLnx умеет передавать значения тегов в SVG через плейсхолдеры вида
`{{ИмяПараметра}}`. После выбора SVG эти имена автоматически появляются в
панели «Параметры SVG» диалога настройки картинки.

Плейсхолдер может содержать безопасное значение по умолчанию:
`{{ИмяПараметра|Значение}}`. Диалог автоматически выбирает для него источник
«Постоянное значение». Это подходит для подписей единиц, семейства и размера
шрифта, начальных углов, цветов и других настроек, которые не обязаны быть
связаны с тегом. Текст при подстановке экранируется как XML, поэтому кавычки,
`&`, `<` и `>` не могут повредить SVG.

Для каждой строки выбираются тег Recorder и передаваемое поле: текущее значение,
одна из четырёх уставок либо цвет соответствующей уставки. Числа записываются с
точкой как десятичным разделителем, цвета — в формате `#RRGGBB`.

Источник «Видимость: значение тега не равно нулю» передаёт `inline` для
ненулевого тега и `none` для нулевого. Его следует назначать параметру атрибута
`display`, чтобы включать и выключать целые группы SVG без скриптов. Для
ручного свойства Вкл/Выкл есть источники «Видимость: включено» и
«Видимость: выключено»; тег им не требуется.

Пример прямой подстановки значения и цвета:

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="200" height="100">
  <rect width="200" height="100" fill="{{AlarmColor}}"/>
  <text x="10" y="55">{{CurrentValue}}</text>
</svg>
```

Готовый параметрический двухканальный прибор находится в
`Assets/SvgTemplates/parametric-dual-gauge.svg`. Для каждой стрелки и цифрового
индикатора используется один параметр `LeftValue` либо `RightValue`: угол
вычисляется из `LeftScaleMin`/`LeftScaleMax` либо
`RightScaleMin`/`RightScaleMax` и ограничивается концами полуокружности.
Также доступны видимость цифровых индикаторов, их цвета, начала и длины
цветовых сегментов, подписи единиц, семейство и размеры шрифтов.

Для параметрической длины круговой дуги в градусах используется выражение
`recorder-deg-dash({{Sweep|120}},198)`, где первый аргумент — угол, второй —
радиус окружности SVG. Перед созданием `TBGRASVG` RecorderLnx переводит угол в
физическую длину дуги. Не применять для этой задачи `pathLength`: BGRASVG не
учитывает его при расчёте `stroke-dasharray`. Проверка шаблона должна выполняться
через тот же BGRASVG-рендерер, а не только в браузере.

Для стрелок шаблон использует `recorder-value-angle(value,min,max,angleMin,angleMax)`
в SVG-атрибуте `transform`. После подстановки тегов препроцессор переводит
значение шкалы в градусы с ограничением по `min..max`. Например, левая шкала
`0..6` соответствует `-180..0°`, правая `0..3` — `180..0°`. Это выражение
обрабатывается RecorderLnx до передачи SVG в BGRASVG; JavaScript не требуется.

Один параметр можно использовать несколько раз. Связи сохраняются в файле
проекта вместе с компонентом картинки и восстанавливаются по ID тега с резервным
поиском по имени.

## Ограничение

Используемый кроссплатформенный растеризатор BGRASVG не выполняет JavaScript из
элемента `<script>`. Параметры нужно использовать непосредственно в SVG/XML,
CSS-атрибутах или поддерживаемых SVG-выражениях. Запуск произвольного JavaScript
потребовал бы отдельного браузерного движка и не входит в этот механизм.
