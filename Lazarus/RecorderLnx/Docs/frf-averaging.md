# Усреднение FRF: оригинал и теория

Проверено 2026-10-19. Воздействие F, отклик Y, индекс j — удар.
Суммы берутся по принятым, не скрытым ударам на одной частотной сетке.

`A = sum(abs(Fj)^2)`, `B = sum(abs(Yj)^2)`,
`C = sum(Yj * conj(Fj))` — комплексный взаимный спектр.

- H1 = C/A: сначала усредняются auto/cross спектры, затем отношение.
- H2 = B/conj(C): тот же принцип; другая модель шума.
- Модуль и фаза извлекаются после оценки комплексной передаточной функции.
- Среднее модулей отдельных FRF не равно комплексному среднему FRF и не
  сохраняет полную фазовую информацию. Простое арифметическое среднее фаз
  также недопустимо из-за перехода через ±pi.
- Нельзя заменять взаимный спектр отношением отдельно усреднённых комплексных
  FFT входа и выхода: случайная фаза ударов может взаимно погасить FFT.

Оригинал: `recorder/plgEvalFRF/forms/uEvalFRFFrm.pas`, evalFRF около 4170.
Режим 0 усредняет `abs(Yj)/abs(Fj)`; H1/H2 суммируют комплексные cross spectra
и соответствующие auto spectra. Текущий `EstimateImpactMoments` сохраняет эти
определения модулей; фаза вычисляется через atan2 комплексной суммы. Это не
означает, что режим 0 является комплексным средним готовых FRF.

Оригинальный «Усреднять» выбирает среднюю для показаний курсора; при одном
видимом канале показывается также отдельный удар, при нескольких — средние.
Обнаруженную несогласованность ShowLines при снятой галке переносить нельзя.

Источники теории:
- https://www.mathworks.com/help/signal/ref/tfestimate.html
- https://www.bksv.com/media/doc/br0458.pdf

Для ударного измерения H1 — обычный исходный выбор при шуме отклика;
H2 полезен при шуме воздействия. Предположения о некоррелированном шуме
не устраняют утечки, нелинейность и ошибки окон. Название legacy режима
следует показывать как «Средняя амплитуд», не подменяя его комплексным средним.
