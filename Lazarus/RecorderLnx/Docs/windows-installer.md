# Установка RecorderLnx в Windows

## Исходники установщика

Установщик Inno Setup находится в:

`installer\RecorderLnx\Win\RecorderLnx.iss`

Сборка выполняется скриптом:

`installer\RecorderLnx\Win\build-installer.ps1`

Готовый файл создаётся в:

`installer\RecorderLnx\Win\Output\RecorderLnx-Setup-<версия>.exe`

## Каталоги

По умолчанию программа устанавливается в:

`C:\Program Files (x86)\Mera\RecorderLnx`

Установщик не подхватывает каталог предыдущей установки. Это защищает штатный
путь от тестовых установок, выполненных с параметром `/DIR`.

Рядом с `RecorderLnx.exe` создаются:

- `plugins` — подключаемые модули;
- `bios` — прошивки устройств и модулей;
- `syscom` — системные библиотеки.

Пользовательские и изменяемые данные по умолчанию находятся в:

`C:\Mera Files`

Там создаются каталоги конфигураций RecorderLnx, калибровок, ресурсов и SDB.
Изменяемые данные нельзя размещать в `Program Files`: обычный пользователь Windows
не имеет права записывать туда без повышения привилегий.

## Файл системных путей

Рядом с `RecorderLnx.exe` установщик создаёт `RecorderLnx.paths.ini`:

```ini
[Paths]
MeraFiles=C:\Mera Files
Config=C:\Mera Files\RecorderLnx\config
Plugins=plugins
Bios=bios
SysCom=syscom
```

Относительные значения разрешаются относительно каталога `RecorderLnx.exe`.
Абсолютные значения используются без преобразования.

Программа должна получать системные каталоги через `uRecorderMeraPaths`, а не
собирать пути самостоятельно. Поиск прошивок дополнительно использует каталог
`Bios` из этого файла.

Если `RecorderLnx.paths.ini` отсутствует, сохраняются прежние платформенные
значения по умолчанию. Это позволяет запускать программу из дерева исходников.

## Тихая установка

Пример:

```text
RecorderLnx-Setup-0.1.0.exe /VERYSILENT /DIR="D:\Mera\RecorderLnx" /MERAFILES="D:\Mera Files"
```

Параметр `/MERAFILES` задаёт корневой каталог изменяемых данных.

## Проверка

После изменения установщика необходимо:

1. полностью собрать `RecorderLnx.lpi`;
2. скомпилировать `RecorderLnx.iss`;
3. выполнить тестовую установку в отдельные каталоги;
4. проверить содержимое `RecorderLnx.paths.ini`;
5. запустить установленный `RecorderLnx.exe`;
6. убедиться, что рабочая конфигурация создаётся в каталоге `Config`;
7. удалить тестовую установку.
