## Нулевая балансировка

Для каждой измерительной точки `i` и каждого тензоканала `e1/e2/e3` хранится
нулевой уровень:

```text
e1_zero[i] = average(e1_raw[i] from balancing record)
e2_zero[i] = average(e2_raw[i] from balancing record)
e3_zero[i] = average(e3_raw[i] from balancing record)
```

В текущей реализации RecorderLnx кнопка `Обновить балансировку` запоминает
текущие значения каналов как `e*_zero`. Это оперативный вариант исходного
требования PDF, где нули записываются не менее 1 минуты при частоте не менее
1 Гц.

Истинные деформации:

```text
e1 = e1_raw - e1_zero
e2 = e2_raw - e2_zero
e3 = e3_raw - e3_zero
```

Если задана температурная поправка `alpha`, из каждой имеющейся деформации
дополнительно вычитается:

```text
alpha * (temperature - reference_temperature)
```

## Модуль упругости

PDF задает температурную зависимость модуля упругости:

```text
E = -2e-7 * temperature^2 - 0.0007 * temperature + 2.0527
```

В документе это значение используется как модуль для нержавейки. В RecorderLnx
компонент уже имеет ручной параметр `E, МПа`; текущая реализация оставляет
ручной `E` основным значением. Температурную зависимость нужно вводить отдельной
настройкой, если потребуется точное следование этому пункту PDF.

## Трехкомпонентная розетка

Для прямоугольной розетки `0/45/90`:

```text
avg = (e1 + e3) / 2
diff = (e1 - e3) / 2
gamma = 2 * e2 - e1 - e3
root = sqrt(diff^2 + (gamma / 2)^2)

eps_max = avg + root
eps_min = avg - root
angle = 0.5 * atan2(gamma, e1 - e3) + position
```

Главные напряжения по методике PDF:

```text
sigma1 = E / 2 * ((e1 + e3) / (1 - nu) +
                  sqrt((e1 - e3)^2 + (2*e2 - e1 - e3)^2) / (1 + nu)) * 1e-6

sigma2 = E / 2 * ((e1 + e3) / (1 - nu) -
                  sqrt((e1 - e3)^2 + (2*e2 - e1 - e3)^2) / (1 + nu)) * 1e-6
```

Эта форма эквивалентна расчету через главные деформации при плоском
напряженном состоянии:

```text
sigma1 = E / (1 - nu^2) * (eps_max + nu * eps_min) * 1e-6
sigma2 = E / (1 - nu^2) * (eps_min + nu * eps_max) * 1e-6
```

`E` задается в МПа, деформации - в мкстрн, результат - МПа.

## Двухкомпонентная розетка

Для двухкомпонентной розетки используются `e1` и `e3`; канал `e2` исключается.

```text
sigma1 = E / (1 - nu^2) * (e1 + nu * e3) * 1e-6
sigma2 = E / (1 - nu^2) * (e3 + nu * e1) * 1e-6
angle = 0
```

## Обрывы каналов

Если одного из тензорезисторов нет, в соответствующих таблицах PDF ставится
прочерк. Для отображения RecorderLnx:

- если у 3-компонентной розетки отсутствует `e2`, считать как пару `e1/e3`,
  `angle` не показывать;
- если отсутствует `e1`, показывать только `sigma2 = E * e3 * 1e-6`;
- если отсутствует `e3`, показывать только `sigma1 = E * e1 * 1e-6`;
- для двухкомпонентной розетки при отсутствии `e1` не показывать `sigma1`, при
  отсутствии `e3` не показывать `sigma2`;
- отсутствующие входы и неполные результаты отображать прочерком.

## Отображение на мнемосхеме

итог по самой нагруженной точке: номер точки и максимальную по модулю истинную
деформацию среди `e1/e2/e3`.
