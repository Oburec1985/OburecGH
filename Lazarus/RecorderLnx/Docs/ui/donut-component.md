# Компонент «Круговая гистограмма»

# Режимы

Компонент мнемосхемы `donut` работает в двух режимах. Режим одного тега
показывает текущее значение как долю заданного диапазона от минимума до
максимума. Цветная дуга ограничена 0–100% кольца, а фактическое значение
показывается в центре. Это режим нового компонента по умолчанию.

Режим нескольких тегов показывает доли их текущих значений.
Ранее сохранённые компоненты без ключа режима остаются в этом варианте.
Каждый выбранный тег образует сектор. Сумма положительных конечных значений
принимается за 100%; отрицательные, `NaN`, бесконечные и отсутствующие значения
дают сектор нулевого размера. При нулевой сумме отображается серое кольцо.

Диалог настройки задаёт режим, заголовок и долю внутреннего отверстия (10–80%).
Для одного тега задаются тег и числовой диапазон. Для нескольких — упорядоченный
список тегов. Порядок задаёт цвет сектора из повторяющейся палитры.
В легенде видны имя и доля каждого отображённого сектора. При малой высоте
легенда ограничена доступным местом.

Настройки хранятся в секции компонента проектного INI: `DonutTitle`,
`DonutHolePercent`, `DonutSingleValueMode`, `DonutRangeMin`, `DonutRangeMax`,
`DonutTagCount`, `DonutTagN` и `DonutTagNId`. ID позволяет
сохранить привязку после переименования тега; имя остаётся резервным способом
восстановления. Копирование компонента переносит все эти настройки.

Отрисовка использует `TBGRAGraphicControl` из BGRA Controls и BGRABitmap.
Пиктограмма лежит в `иконки/my/42/donut.png` и включена ресурсом в командный
ImageList под индексом `CIconDonut`.
Зависимости закреплены подмодулями `Lazarus/third_party/bgrabitmap` и
`Lazarus/third_party/bgracontrols`; после клонирования проекта требуется
`git submodule update --init --recursive` и регистрация пакетов
`bgrabitmappack.lpk`, `bgracontrols.lpk` в Lazarus.
