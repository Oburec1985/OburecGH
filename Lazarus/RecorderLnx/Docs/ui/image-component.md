# Компонент «Картинка»

Компонент `Image` размещается на пользовательской мнемосхеме кнопкой `Img`.
В режиме редактирования компонент показывается контрастной светлой заливкой
с толстой яркой рамкой, поэтому его видно даже без назначенной картинки.
В режиме просмотра служебное оформление не рисуется.
При входе в редактор сохраняется уже отображаемая картинка. Для нового
визуального контрола сначала используется файл, соответствующий текущему
значению тега, а при отсутствии данных — первый реально существующий файл из
таблицы. Пустая или повреждённая первая строка не должна очищать превью.
При перетаскивании и изменении размера изображение перерисовывается по новым
границам без повторного чтения файла.

Представление реализовано оконным `TCustomControl`, а не `TGraphicControl`.
Растровый компонент не должен рисовать на Canvas родительской панели:
design-time изменение её рамки или геометрии может стереть такое изображение
уже после успешного `Paint`.

Настройка открывается двойным щелчком:

- без тега всегда отображается первая картинка из таблицы;
- с тегом выбирается строка, числовое значение которой совпадает с последним
  значением тега;
- если строка не найдена, файл отсутствует или не читается, остаётся рамка;
- в третьем столбце таблицы показывается предварительный просмотр файла.

Пути к файлам сохраняются в `gui.ini` относительно каталога этого файла.
Модель хранится в `TRecorderImageComponent`, отрисовка — в
`TRecorderImageView`. Редактируемая форма диалога:
`UI/uRecorderImageSettingsDialog.lfm`.

## Рамка в режиме редактирования

После вывода изображения рамка выделения рисуется только контуром:
`Canvas.Brush.Style` перед `Canvas.Rectangle` обязательно должен быть
`bsClear`. Иначе LCL заполнит внутреннюю область текущим цветом кисти и
сотрёт уже нарисованную картинку. Проверка: назначенная картинка должна быть
видна и в рабочем режиме, и сразу после включения редактирования, и во время
изменения размера.
