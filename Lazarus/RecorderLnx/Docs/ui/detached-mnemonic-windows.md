# Открепляемые пользовательские формуляры

Пользовательский формуляр можно показывать во вкладке главного окна или в отдельном окне. Встроенные страницы «Цифровой формуляр» и «Базовая страница» не открепляются.

## Управление

1. Открыть диалог «Формуляры».
2. Выбрать пользовательский формуляр.
3. Нажать «Открепить окно».

У отдельного окна есть собственная панель редактирования. Закрытие отдельного окна возвращает формуляр во вкладку главного окна.

Панель отдельного окна использует тот же `ilCommandButtons`, те же индексы
изображений, порядок и размеры кнопок, что и редактор в главном окне.
Пока формуляр откреплён, его вкладка в главном окне не показывается.

## Хранение состояния

Для страницы в GUI-конфигурации сохраняются:

- признак отдельного окна;
- координаты и размер;
- индекс монитора;
- развёрнутое состояние.

При следующей загрузке проекта окно восстанавливается на сохранённом мониторе. Если монитор недоступен, окно переносится в рабочую область доступного экрана.

## Архитектура

Вкладка и отдельное окно используют один `TRecorderFormPage`, поэтому состав и настройки компонентов не дублируются. У каждого отдельного окна свой `TFormEditorController`, панель инструментов и поверхность отображения. Изображениями панелей владеет главная форма; отдельное окно только использует переданный общий `ImageList`.

Отдельные окна обновляются общим циклом отображения только пока видимы. Перед сохранением проекта их текущее положение записывается в модель страницы.
