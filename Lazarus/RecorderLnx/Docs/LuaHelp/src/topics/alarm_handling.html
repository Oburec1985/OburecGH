RecorderLnx/Аварии

Обработка аварии

Пример обработки предупреждения и аварии тега.

Пример использования

local уровень = getTagAlarmLevel("Температура")
if уровень == 2 then
  logMessage("Авария")
elseif уровень == 1 then
  logMessage("Предупреждение")
end

Двойной щелчок по функции в редакторе вставляет заготовку кода.
