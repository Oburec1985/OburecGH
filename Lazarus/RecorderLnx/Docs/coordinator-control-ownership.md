# Управление Recorder из любой RCPanel

Recorder больше не привязан к адресу RCPanel в coordinator-client.ini.
Старый BaseUrl игнорируется. InstanceId Recorder сохраняется постоянно;
владелец управления и ClaimId существуют только во время работы.

Все панели обнаруживают Recorder через UDP. Объявление не захватывает его.
В RCPanel 0.1.29 пользователь выбирает Recorder и нажимает «Захватить».
Для занятого Recorder доступна кнопка «Перехватить» с предупреждением.
«Освободить» возвращает Recorder в свободное состояние. Запуск через
HostAgent также запрашивает захват. Сам сбор данных от захвата не зависит.

Recorder проверяет доступность и ID запросившей панели через HTTP, затем
отправляет ей hello/heartbeat. Только этот обмен подтверждает управление.
При отсутствии успешного обмена в течение 15 секунд захват освобождается;
текущее измерение при этом не останавливается. После перезапуска Recorder
свободен. Адрес владельца не записывается в INI.

Команды принадлежат конкретному ClaimId и поколению захвата. Старые команды
и результаты не переходят новой панели. События сохраняют исходного владельца
в durable outbox; принадлежность длительной записи сохраняется отдельно.
Повтор ранее завершённого захвата не должен возвращать управление.

Если применяется общий AuthToken, он должен совпадать у панели и Recorder.
Порты UDP: RCPanel 38765, Recorder 38766. HTTP панели обычно 8765.
Перехват требует явного подтверждения; фоновое обнаружение владельца не меняет.

Проверки: RecorderCoordinatorOwnershipTest, CoordinatorDiscoveryClaimTest,
CoordinatorClaimSessionTest, CoordinatorOwnershipIntegrationTest. Последний
запускает production Recorder client и две настоящие HTTP-панели в изолированной
сети: захват, отказ без force, перехват, старые команды, release, replay и lease.
GUI проверяется CoordinatorClaimUiProbe на настоящей LCL-форме.

Примечание: первый force-пакет отправляется один раз, повторы идут без force,
чтобы задержавшийся запрос не отобрал управление обратно. При потере первого
пакета пользователь повторяет явный перехват после ограниченного ожидания.
