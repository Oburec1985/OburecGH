# Семантический поиск по исходникам оригинального Recorder

Исходники оригинального Windows Recorder в `D:\works\windev-v3.9` включены в
локальный индекс Qdrant проекта AGrav MemoryDB. Индекс используется как
навигационный слой при разработке RecorderLnx и не изменяет исходные файлы.

Индексируются ядро и UI Recorder (`mr`, `rc_core`, `rc_guisrv`, `rc_conui`,
`rc_ctrpn`, `rc_utils`), SDK `plugins/rcsdk`, а также используемые RecorderLnx
исходники MTC/MDP, MIC-140 и примеры Mebius DAQ. Поддерживаются C/C++, IDL,
Pascal, RC и include-файлы; legacy-кодировки читаются как UTF-8/CP1251/CP866.

## Порядок исследования оригинала

1. Вызвать MCP-инструмент `search_original_recorder_sources`, передав описание
   поведения и известные имена классов, методов, свойств тегов или протокола.
2. Ограничить выдачу 5–12 чанками. Каждый результат содержит абсолютный путь,
   символ и диапазон строк.
3. Прочитать найденный диапазон непосредственно из исходного файла.
4. Точным поиском `rg` проверить определения, вызывающие функции, константы и
   соседние реализации. Эмбеддинг помогает найти место, но не является
   доказательством поведения программы.
5. После намеренного изменения эталонного дерева выполнить
   `sync_original_recorder_sources`. При обычных изменениях RecorderLnx индекс
   оригинала обновлять не требуется.

Конфигурация MCP находится в `C:\Users\User\.codex\config.toml`. Новые
инструменты становятся доступны в новом сеансе Codex после перезапуска среды.

См. также [current-plan.md](../architecture/current-plan.md) и
[original-recorder-block-recording.md](original-recorder-block-recording.md).
