# Техническое Задание (ТЗ) на модуль калибровки и поверки измерительных модулей

## 1. Назначение и области применения

Модуль калибровки и поверки (в составе ПО `RecorderLnx`) предназначен для автоматизации процессов метрологической аттестации, периодической поверки и первичной калибровки измерительных каналов (включая измерительные модули MIC-140, MIC-185, MC-201 и сторонние устройства).

Модуль обеспечивает формирование гибких сценариев поверки, управление генераторами, калибраторами, коммутаторами и измерителями, получение данных от проверяемых каналов и образцовых источников, математический расчет заданных оценок и автогенерацию протоколов поверки.

Архитектура модуля развивается с учетом концепции автоматизированных систем поверки серии Recorder (на базе Codelator / AutoCalibrate).

---

## 2. Архитектура сценария, стадийность и проверка диапазонов (Stages & Ranges)

### 2.1. Стадийность поверки
Сценарий поверки/калибровки состоит из последовательности независимых или выбираемых оператором **Стадий (Stages)**.

- **Примеры стадий**:
  1. *Стадия 1*: Подготовка и проверка нулевых уровней / собственного шума.
  2. *Стадия 2*: Поверка поддиапазона $\pm 10\text{ В}$ (DC, линейность, гистерезис).
  3. *Стадия 3*: Поверка поддиапазона $\pm 1\text{ В}$ (DC, линейность, гистерезис).
  4. *Стадия 4*: Поверка диапазона AC (АЧХ и ФЧХ на заданной сетке частот).
  5. *Стадия 5*: Оценка коэффициента взаимных наводок (Crosstalk) между каналами.
- **Свойства стадии**:
  - Идентификатор, наименование и описание стадии.
  - Настройки аппаратного диапазона измерительного модуля для данной стадии.
  - Условия перехода к следующей стадии (автоматически, по подтверждению оператором, по стабильности).
  - Индивидуальный список проверяемых каналов, полок и контрольных точек.
  - Возможность выборочного перезапуска отдельной стадии без потери результатов других стадий.

## 3. Настройка приборов для каждой контрольной точки (KT Device Presets)

Для каждой контрольной точки (КТ) в сценарии задаётся профиль состояния аппаратного комплекса оборудования:

### 3.1. Подключаемые приборы и настройки для КТ
1. **Эталон / Генератор / Калибратор**:
   - Тип и формы выставляемого сигнала (DC, Синус, Меандр, Пила, Шум).
   - Амплитудное / действующее значение (В, мА, Гц).
   - Частота $f_{ref}$ и постоянное смещение $U_{offset}$.
   - Состояние выхода (Output ON/OFF, импеданс 50 Ом / High-Z).
2. **Измерительный модуль (проверяемое устройство)**:
   - Активный физический диапазон (Gain / Attenuation).
   - Режим входа (Open/Ground/AC/DC/Differential).
   - Частота дискретизации $F_s$ и тип входных фильтров.
3. **Коммутатор / Релейная матрица**:
   - Задание схемы коммутации реле (маршрутизация сигнала от генератора к целевым каналам).
   - Команды замыкания/размыкания ключей.
4. **Нормирующий усилитель / Преобразователь**:
   - Коэффициент усиления $G$, полоса пропускания фильтра, опорное напряжение.

## 4. Кабельные мультипликаторы и масштабные коэффициенты каналов

В реальных метрологических схемах в разных каналах применяются различные шунты, емкости, делители напряжения и датчики.

### 4.1. Параметры канала
Для каждого физического канала задаются:
- **Мультипликатор (Scale Multiplier $K_{ch}$)**: учитывать коэффициент деления шунта, входной емкости или чувствительность датчика (например, $K_{ch} = 100.0$ для шунта/делителя 1:100).
- **Аддитивное смещение (Zero Offset $B_{ch}$)**: для компенсации начального кабельного смещения.

### 4.2. Формула пересчета
Расчет первичных физических величин из сырых отсчетов канала выполняется по формуле:
$$Y_{calc}(t) = Y_{raw}(t) \cdot K_{ch} + B_{ch}$$
Все последующие вычисления оценок и критериев допусков проводятся над масштабированным значением $Y_{calc}$.

## 5. Конфигурирование порции данных (Acquisition Portion)

Для устранения переходных процессов при смене состояния приборов и обеспечения достоверности статистических оценок на каждой КТ конфигурируется порция сбора.

### 5.1. Параметры порции
- **Время выдержки / успокоения (Settling Time)**:
  - Задержка (в мс или секундах) после выдачи команд настройки приборам перед запуском накопления данных.
  - Позволяет завершиться переходным процессам в калибраторе, реле коммутации и входных RC-цепях.
- **Размер порции (Portion Size)**:
  - *По времени*: сбор данных длительностью $T$ секунд.
  - *По количеству отсчетов*: сбор блока из $N$ сэмплов (например, 4096 / 8192 для БПФ).
  - *По критерию стабилизации*: сбор данных до снижения скользящего стандартного отклонения $\sigma$ ниже заданного порога $\sigma_{threshold}$.

## 6. Вычисляемые оценки (Statistical & Metric Estimates)

Для каждой контрольной точки пользователь настраивает набор математических оценок, по которым выполняется расчет и проверка допусков.

### 6.1. Настройка оценок
- **Математическое ожидание ($\bar{Y}$ / Mean)**: среднее постоянное значение порции.
- **СКЗ / RMS (Root Mean Square)**: среднеквадратическое значение сигнала.
- **Шум / Standard Deviation ($\sigma$)**: стандартное отклонение от переменной составляющей.
- **Размах (Peak-to-Peak: $Y_{max} - Y_{min}$)**: максимальный пиковый размах шума или сигнала.
- **Амплитуда первой гармоники БПФ ($A(f_{gen})$)**: амплитуда сигнала на частоте генератора для расчета АЧХ.
- **Фазовый сдвиг ($\Delta \phi(f)$)**: сдвиг фазы относительно опорного сигнала для расчета ФЧХ.
- **Коэффициент гармоник (THD)** и **Медиана (Median)**.

---

## 7. Критерии оценки и допуски контрольных точек (Check Criteria)

На основе выбранных оценок для КТ формируются метрологические критерии:

### 7.1. Набор критериев
- **Отклонение мат. ожидания**: $\Delta_{mean} = \bar{Y} - Y_{ref}$.
- **Оценка уровня шума**: проверка $\sigma \le \sigma_{max}$ или $PkPk \le PkPk_{max}$.
- **Отклонение АЧХ**: проверка коэффициента передачи $K(f) = A_{out}(f) / A_{in}(f)$ на соответствие допуску.
- **Отклонение ФЧХ**: проверка сдвига фазы $\Delta \phi(f)$ на соответствие допуску.

### 7.2. Задание допусков (Tolerances)
- Абсолютный допуск ($\pm \Delta_{max}$).
- Относительный допуск ($\pm \delta\%$).
- Комбинированный допуск ($\pm (a\% \cdot Y + b\% \cdot Y_{FS})$).
- Статусы контроля: `PASS` (Годен), `FAIL` (Не годен), `WARNING` (Предупреждение).

## 8. Проход по полкам, гистерезис и многопроходная поверка

### 8.1. Проход по полкам
- **Прямой ход (`Up`)**: подъем физического уровня от $X_{min}$ до $X_{max}$.
- **Обратный ход (`Down`)**: спуск от $X_{max}$ до $X_{min}$.

### 8.2. Вычисление гистерезиса
Для одинаковых полок уровня $X_k$ вычисляется значение гистерезиса:
$$\Delta_{hys}(X_k) = |Y_{Up}(X_k) - Y_{Down}(X_k)|$$
Сопоставление $\Delta_{hys}(X_k)$ с допустимой уставкой гистерезиса $\delta_{hys}$.

### 8.3. Многопроходная поверка (Multi-pass Sweep)
- Выполнение $N$ полных циклов `Up` $\rightarrow$ `Down`.
- Накопление статистики воспроизводимости, разброса измерений и выявление временного дрейфа параметров между проходами.

---

## 9. Источники эталонного значения (Reference Sources)

1. **Статический эталон (Из преднастроек / Profile Table)**:
   - Значение эталона считывается из профиля поверки (константа для полки).
2. **Динамический эталон (Сличение по каналу обратной связи / Feedback Reference Channel)**:
   - Значение эталона в реальном времени измеряется опорным каналом (эталонным вольтметром / образцовым модулем).
   - Расчет погрешности: $\Delta(t) = Y_{test}(t) - Y_{ref\_channel}(t)$.

---

## 10. Многоканальная обработка и перекоммутация

### 10.1. Режимы обработки каналов
- **Параллельная поверка**: одновременный опрос группы каналов.
- **Последовательная поверка**: поочередная поверка каналов $1..M$.

### 10.2. Перекоммутация
- **Автоматическая**: переключение реле матричным коммутатором перед КТ.
- **Интерактивная (Операторская)**: вывод диалога с инструкциями по переключению кабелей и ожидание кнопки *"Далее"*.
