# RecorderLnx Docs

Документация RecorderLnx разложена по тематическим папкам. Корень каталога
оставлен как оглавление и место для стабильных входных ссылок.

## Разделы

- [architecture](architecture/) - архитектура, жизненный цикл, правила разработки, план.
- [devices](devices/) - приборы, протоколы, аппаратный lifecycle.
- [ui](ui/) - мнемосхемы, настройки, визуальные компоненты.
- [algorithms](algorithms/) - спектры, алгоритмы, вычислительные пайплайны.
- [calibration](calibration/) - SDB, градуировки, тензо-ГХ.
- [sql](sql/) - SQL БД, Firebird, исторические тренды.
- [setup](setup/) - установка, VM, кодировки, сетевые интерфейсы.
- [original](original/) - заметки по оригинальному Windows Recorder.
- [errors](errors/) - долговременная память расследований.
- [screens](screens/) - изображения и схемы.
- [old](old/) - устаревшие, но полезные исторические материалы.
