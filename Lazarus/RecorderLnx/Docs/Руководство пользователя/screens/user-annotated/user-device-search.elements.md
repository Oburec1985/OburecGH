# user-device-search

Источник: `../юзер/AutoSearch.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Выбор устройства | Флажок включает найденный прибор в список добавляемых источников. | Space |
| 2 | Добавить | Добавляет отмеченные устройства и создаёт их источники/каналы. | Enter |
| 3 | Отмена | Закрывает результаты поиска без изменения проекта. | Esc |
