# user-tag-main

Источник: `../юзер/Настройка каналов.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Вкладки | Параметры, дополнительные свойства и уставки тега. | Ctrl+Tab |
| 2 | Имя | Имя тега в проекте. | — |
| 3 | Физическая единица | Ручная единица либо единица конечного узла pipeline. | — |
| 4 | Автоединицы | Автоматически получает единицу из конечного узла pipeline. | — |
| 5 | Адрес | Привязка тега к источнику данных. | — |
| 6 | Описание | Назначение и пояснение канала. | — |
| 7 | Fs | Частота опроса/публикации тега. | — |
| 8 | Нижняя граница | Нижняя граница рабочего диапазона. | — |
| 9 | Верхняя граница | Верхняя граница рабочего диапазона. | — |
| 10 | Автодиапазон | Вычисляет диапазон по источнику и ГХ. | — |
| 11 | Использовать аппаратную ГХ | Включает характеристику источника. | — |
| 12 | Аппаратная ГХ | Характеристика текущего режима источника данных. | — |
| 13 | Использовать канальную ГХ | Включает пользовательскую цепочку преобразований. | — |
| 14 | Канальная ГХ | Последовательность пользовательских преобразований. | — |
| 15 | OK | Сохраняет и закрывает форму. | Enter |
| 16 | Отмена | Закрывает без сохранения. | Esc |
| 17 | Применить | Сохраняет, оставляя форму открытой. | Enter |
