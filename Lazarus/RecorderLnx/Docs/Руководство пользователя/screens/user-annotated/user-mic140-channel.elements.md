# user-mic140-channel

Источник: `../юзер/MIC140_Chan.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Диапазон измерения | Выбирает аппаратный входной диапазон канала. | — |
| 2 | ГХ термопары | Назначает характеристику термопары. | — |
| 3 | Выбор/очистка ГХ | Открывает базу ГХ или очищает назначение. | — |
| 4 | Канал ТХС | Связывает канал холодного спая. | — |
| 5 | ТХС по умолчанию | Использует стандартное назначение термоканала. | — |
| 6 | Диапазон температуры | Показывает диапазон выбранной ГХ. | — |
| 7 | Программный баланс | Задаёт смещение канала в кодах. | — |
| 8 | OK | Сохраняет свойства канала. | Enter |
| 9 | Отмена | Закрывает форму без сохранения. | Esc |
