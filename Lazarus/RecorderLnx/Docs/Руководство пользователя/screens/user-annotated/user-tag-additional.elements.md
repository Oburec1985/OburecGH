# user-tag-additional

Источник: `../юзер/Настройка каналов дополнительно.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Вкладки | Переключают разделы настройки тега. | Ctrl+Tab |
| 2 | Вычисляемые оценки | Включает MO, RMS, максимумы и другие итоговые оценки. | — |
| 3 | Оценка по умолчанию | Определяет значение компонентов без явного выбора. | — |
| 4 | Длина порции | Задаёт окно расчёта оценки. | — |
| 5 | Экспоненциальное сглаживание | Управляет сглаживанием результата. | — |
| 6 | SCADA | Разрешает использование канала в SCADA-механизмах. | — |
| 7 | OK | Сохраняет и закрывает форму. | Enter |
| 8 | Отмена | Закрывает без сохранения. | Esc |
| 9 | Применить | Сохраняет, оставляя форму открытой. | Enter |
