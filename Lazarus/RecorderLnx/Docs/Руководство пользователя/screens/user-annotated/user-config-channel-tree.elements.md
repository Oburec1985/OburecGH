# user-config-channel-tree

Источник: `../юзер/cfg_channels_tree.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Вкладки | Переключают разделы общей настройки RecorderLnx. | Ctrl+Tab |
| 2 | Доступные каналы | Список каналов, ещё не включённых в выбранную структуру. | — |
| 3 | Фильтр | Поиск выбранных каналов. | — |
| 4 | Таблица/дерево | Выбор плоского или иерархического представления. | — |
| 5 | Дерево групп | Группы и каналы проекта; значок показывает состояние/активность. | — |
| 6 | Добавить | Добавляет отмеченный доступный канал. | — |
| 7 | Удалить | Возвращает выбранный канал в доступные. | — |
| 8 | Свойства | Открывает настройку выбранного канала. | — |
