# user-config-hardware

Источник: `../юзер/cfg_hardw.png` (оригинал не изменяется).

| № элемента | Назначение | Описание как работает | Клавиши |
|---:|---|---|---|
| 1 | Вкладки | Переключают разделы общей настройки. | Ctrl+Tab |
| 2 | Дерево устройств | Показывает MIC-140, MIC-185 и Mera File; двойной щелчок открывает свойства. | — |
| 3 | Сетевой интерфейс | Выбирает локальный адаптер поиска/соединения. | — |
| 4 | Адрес и порт | Задают проверяемый сетевой узел. | — |
| 5 | Проверка TCP | Проверяет доступность введённого адреса и порта. | — |
| 6 | Добавить | Добавляет источник данных. | — |
| 7 | Удалить | Удаляет выбранный источник из проекта. | Delete |
| 8 | Свойства | Открывает свойства выбранного источника. | — |
| 9 | Автопоиск | Ищет поддерживаемые приборы в сети. | — |
| 10 | Ping | Проверяет связь с выбранным прибором. | — |
| 11 | OK | Сохраняет изменения и закрывает форму. | Enter |
| 12 | Закрыть | Закрывает форму без новых изменений. | Esc |
| 13 | Применить | Сохраняет изменения, оставляя форму открытой. | Enter |
