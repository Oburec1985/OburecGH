# Атомарность кадра FIFO MIC-140

Маркер правила: `RLNX_ATOMIC_DEVICE_FRAME_2026_07_28`.

MIC-140-48v3 передаёт одну строку измерений в порядке:

`48 AIn + 7 TIn`.

Весь кадр должен проходить через декоммутацию и межпоточное кольцо одной
структурой вместе с `FirstTimeSec`, `SampleRateHz` и `SampleCount`.

Нельзя передавать AIn через очередь, а синхронные TIn брать из общего
`Last...Snapshot`. Производитель может заменить такой снимок следующим
сетевым пакетом до обработки потребителем. Это сохраняет правильное среднее,
но создаёт ложные скачки на границах блоков и искажает запись.

Проверка после изменения тракта:

- `ChannelCount` принятого блока равен полному stride;
- TIn извлекаются из хвоста того же блока;
- время и число отсчётов AIn/TIn совпадают;
- аппаратный прогон не имеет gaps, duplicates и resync;
- порядок TIn в записи совпадает с порядком строк сетевого дампа.
