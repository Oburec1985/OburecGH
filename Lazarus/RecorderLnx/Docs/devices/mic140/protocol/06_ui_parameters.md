| Элемент UI | IDC | Переменная | Единицы в UI |
|------------|-----|------------|--------------|

| Время переходного процесса | EDIT_PERIOD_DECAY | `period_decay` | мкс (`× MULT_PERIOD_DECAY`) |
| Время заземления 2 | EDIT_PERIOD_DECAY2 | `period_decay2` | мкс |
| Опрос всех каналов | — | `flag_allch_sampl` | bool |
| Заземление | — | `flag_chan_ground` | bool |
| Авторасчёт | — | `mode_auto_calc_period_delay` | bool |

При потере фокуса полей decay/aver вызывается `CheckPeriodDelay(freq, …)`.
`freq` берётся как фактическая частота AIn-канала через `GetFreqSFor`, а не как
округлённая строка из UI.

Подробное описание формул и пример расчёта (10.000 Гц → 327 точек при
эффективной поправке ISR `103/640` и 51 канале) —
[08_timing_and_count_aver.md](08_timing_and_count_aver.md).

# Компенсация холодного спая MIC-140-48v3

Для термопарного входа итоговое значение считается строго в таком порядке:

1. код AIn преобразуется аппаратной ГХ входа в мВ;
2. код связанного TIn преобразуется его аппаратной ГХ в температуру холодного
   спая;
3. температура холодного спая обратной термопарной ГХ преобразуется в мВ;
4. эти мВ складываются с мВ AIn;
5. сумма преобразуется прямой термопарной ГХ в градусы Цельсия.

У 48v3 видимый список из семи температурных каналов соответствует физическим
каналам `T6..T12`, а не `T1..T7`. Файлы аппаратной калибровки и адреса
дескрипторов flash должны использовать именно физические номера.

В UI, адресах и именах тегов также используются только физические обозначения:
пятый элемент внутреннего массива показывается как `T10`, а создаваемый тег
получает адрес вида `{node}-t10`. Число `5` остаётся только внутренним индексом
массива и не должно попадать в пользовательские таблицы или журналы.

Карта корректоров по умолчанию воспроизводит
`CModuleMIC140_48v3::TINCOR_AIN_INDEX_48V3` оригинального Recorder:

| AIn | корректирующий TIn |
|---|---|
| 1–5 | T10 |
| 6–10 | T9 |
| 11–15 | T8 |
| 16–20 | T7 |
| 21–29 | T6 |
| 30–34 | T7 |
| 35–39 | T8 |
| 40–44 | T9 |
| 45–48 | T10 |

`T11` и `T12` входят в экспортируемый список служебных каналов, но в штатной
таблице корректоров AIn не используются. При ручном чтении аппаратной ГХ
термопарного AIn RecorderLnx также читает ГХ назначенного TIn, чтобы канал не
переходил молча на прямой пересчёт термопары без КХС.
