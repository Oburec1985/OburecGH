# Включение и отключение источников данных

Состояние источника хранится в канонической записи проекта
`dataSources[].enabled`. Значение по умолчанию — `true`, поэтому старые
конфигурации продолжают работать без миграции.

Отключённый источник остаётся в проекте вместе с тегами и аппаратными
настройками, но:

- не проходит сетевой `TestLink` при построении дерева;
- не регистрируется как активный;
- не создаётся runtime-фабрикой;
- не открывает соединение, не программируется и не собирает данные.

Состояние переключается контекстным меню узла дерева. Отключённый узел
показывается неактивной иконкой и префиксом `[ВЫКЛ]`. Изменение считается
изменением набора источников и применяется после `Применить` или `OK`.
