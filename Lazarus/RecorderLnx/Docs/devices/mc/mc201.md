## Scan Start Notes

The standalone test now follows the critical original Recorder setup step from
`CCDevice::Config()`:

1. `CMD_RESETSCANMAIN`.
2. `CMD_CONFIGSCANMAIN` with CC81 Ethernet timer values from `cc81ifc.cpp`:
   `scale=1`, `period=640`; the command receives `0` and `639`.
3. MC-201 module programming from `Mc201.cpp`: module IDMA descriptor,
   stop/reset module scan, RAW/DBL/MIX channel chains, control-register write,
   grid/frequency/channel-list commands, then `GET_FINAL_FLAG_CC`.
4. Controller scan descriptors: `CMD_APPENDSCANMAIN`, `CMD_ADDCHANNELMODULE`,
   `CMD_SCAN_SET_CHANS`.
5. ADC start trigger list and `CMD_START_TRIGGERSTARTADC`.
6. Runtime start/stop: `CMD_STARTSCANMAIN` / `CMD_STOPSCANMAIN`.

Without step 2 the command `STARTSCANMAIN` succeeds, but no stream packets are
received. With it, the live acceptance command below passed on 2026-07-14:

```powershell
D:\works\OburecGH\Lazarus\Tests\RecorderTests\Mc201ProtocolDebug\lib\Mc201ProtocolDebug.exe --cli --acceptance-ms=5000 --update-ms=200 --timeout-ms=1200 --connect-attempts=3 --connect-retry-ms=1000 --slots=4
```

Observed result: `25` update blocks for 5 seconds at the default `200 ms`
update interval, with `6738` raw Ethernet frames. Typical raw frame sizes were
`266`, `532`, and `798` words.
