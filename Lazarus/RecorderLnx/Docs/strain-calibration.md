# Встроенный тензокалькулятор RecorderLnx

## Назначение

Модуль `Calibrations/Strains` создаёт канальную градуировочную характеристику для тензометрического входа. Пользователь выбирает схему моста, параметры датчика и материала, входные и выходные единицы. В runtime расчёт выполняется без итераций:

`y = Offset + K1·x + K2·x²`.

Коэффициенты вычисляются только при настройке ГХ и сохраняются вместе с проектом. Полином принимается, только если его максимальная ошибка на 201 контрольной точке рабочего диапазона не превышает 0,1% полной шкалы.

## Поддерживаемые схемы

1. Четверть моста, один активный тензорезистор.
2. Полумост: продольный и поперечный датчики с учётом коэффициента Пуассона.
3. Полумост: два продольных датчика в противофазе.
4. Полный мост с одним активным плечом.
5. Полный мост с двумя продольными датчиками в противофазе.
6. Полный мост: два продольных и два поперечных датчика.
7. Полный мост с четырьмя активными продольными датчиками.

Распределение относительных изменений сопротивления по плечам соответствует методике исходного тензокалькулятора. Знак сигнала един для прямого и обратного расчёта: `Uвых = V2 − V1`.

## Физическая модель

Механическое изменение сопротивления:

`m = S·ε`, где `S` — коэффициент тензочувствительности, `ε` — относительная деформация.

Температурная добавка:

`t = (αt + S·βm)·ΔT`.

После назначения `m` и `t` плечам схемы рассчитывается точный выход моста:

`V1/Uпит = R2/(R1+R2)`, `V2/Uпит = R4/(R3+R4)`, `x = V2/Uпит − V1/Uпит`.

При питании напряжением `Uпит` задаётся непосредственно в вольтах. При
питании током пользователь вводит `Iпит` в мА, а напряжение моста рассчитывается
для каждой точки деформации:

`R12 = R0·(2+d1+d2)`, `R34 = R0·(2+d3+d4)`,
`Rэкв = R12·R34/(R12+R34)`, `Uпит = (Iпит/1000)·Rэкв`.

Поэтом при токовом питании учитывается изменение эквивалентного сопротивления
моста. Для абсолютных единиц `В` и `мВ` используется это расчётное напряжение; относительные
единицы `dU/U` и `мВ/В` от амплитуды питания не зависят.

Три опорные точки `−εmax`, `0`, `+εmax` задают квадратичный полином. Затем он проверяется на всём диапазоне. Если ошибка больше 0,1%, диалог не сохраняет ГХ и предлагает уменьшить рабочий диапазон.

## Параметры настройки

- схема включения;
- коэффициент тензочувствительности `S`;
- коэффициент Пуассона `ν`;
- модуль Юнга в МПа (например, для стали `200000` МПа);
- номинальное сопротивление датчика;
- тип питания моста: напряжение или ток;
- напряжение в вольтах либо ток в миллиамперах;
- изменение температуры, ТКСО датчика и ТКЛР детали;
- рабочий диапазон в микродеформациях;
- вход при питании напряжением: `dU/U`, `мВ/В`, `В`, `мВ`;
- вход при питании током: `мВ`, `мВ/мА`, `Ом`;
- выход: относительная деформация, `мкстр`, `Па`, `МПа`, `мВ`.

## Использование

В настройках канала откройте канальную ГХ, нажмите «Добавить» и выберите «Тензометрическая ГХ (встроенный калькулятор)». После сохранения ГХ назначается каналу и участвует в обычной цепочке канальных градуировок RecorderLnx.

## Ограничения

- Модуль рассчитывает напряжённость как `σ = E·ε`; это одноосная линейно-упругая модель.
- Температура задаётся фиксированным параметром ГХ. Динамическая температурная компенсация отдельным каналом пока не реализована.
- Значения вне заданного рабочего диапазона вычисляются тем же полиномом, но гарантированная ошибка 0,1% относится только к настроенному диапазону.
