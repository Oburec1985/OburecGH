# X-курсор осциллограммы менял координату при zoom

## Симптом

После мышиного zoom вертикальный измерительный курсор показывал другое значение
X, хотя пользователь его не перемещал.

## Причина

`fXCursors` хранил положение как долю текущего viewport (`0..1`). Отрисовка и
легенда каждый раз вычисляли `XMin + fraction * (XMax - XMin)`, поэтому любое
изменение диапазона оси изменяло мировое значение курсора.

## Исправление

Курсор хранит абсолютный X оси. Pixel-to-world выполняется только при его
перетаскивании; рисование и hit-test используют world-to-pixel. Начальные
позиции 33%/67% вычисляются один раз после появления первого кадра. Если zoom
исключил координату из окна, курсор не рисуется, но значение сохраняется.

## Проверка

Полная forced Windows-сборка RecorderLnx в отдельный EXE завершилась с exit
code 0. Визуальная проверка в работающем GUI остаётся.
