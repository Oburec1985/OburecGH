# 2026-08-18 - Tag description imported from ODS is overwritten

## Symptom

After changing channel descriptions through the ODS tag import table, opening
MIC185 tag settings shows the old default text such as `MIC183/185 channel
156-1`.

## Confirmed Facts

- `uRecorderTagTableExchange.pas` reads the ODS `Описание канала` column and
  assigns it through `lTag.Description := ARows[I].Description`.
- `TRecorderMic185SettingsForm.EnsureTagForGridRow` unconditionally rewrote
  existing tag descriptions to `MIC183/185 channel <address>`.
- `uRecorderMic185DataSource.pas` had two more unconditional default
  description assignments during MIC185 project/source tag synchronization.
- MIC-140 had the same pattern in datasource tag creation and source settings.
- The latest reproduced text `185-{156-1}; type=R8; freq=100; file=4000`
  is generated by MERA signal binding/default-description paths, not by
  MIC185 hardware settings.

## Change

MIC185 and MIC-140 default descriptions are now assigned only when a tag is
newly created or when its description is empty. Existing user descriptions
imported from ODS or edited in the tag dialog are preserved when
opening/applying source settings and when loading/synchronizing hardware tags.
The generic tag settings dialog now also allows clearing a single tag
description; for multi-select, an empty field still means "leave mixed
descriptions unchanged".
MERA file/source binding now also generates its technical default description
only for empty descriptions.
