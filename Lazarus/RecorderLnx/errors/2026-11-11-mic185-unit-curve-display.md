# MIC-185: строка аппаратной ГХ не обновлялась при смене единиц

## Подтверждено

При выборе мВ/Ом/мкстрн меняется программный пересчёт одного приборного диапазона. UnitComboSelect применял единицы, но не вызывал обновление аппаратной ГХ. Дополнительно MIC185.ReadState форматировал только исходный ADC-коэффициент: одного repaint было недостаточно.

## Исправление

Общий обработчик единиц вызывает UpdateHardwareCurveText/Buttons после успешного model commit. MIC185.ReadState проецирует зарегистрированную ADC-ГХ через тот же Mic185ApplyUnitLine, фактический настроенный ток и уже зарегистрированную ГХ тока. Совместимый префикс учитывается; b остаётся смещением ADC в кодах. ReadState не загружает CSV и не обращается к прибору. MeasRangeIndex, ChannelMode и исходный объект ADC-ГХ не изменяются.

## Проверка

SourceUnitPipelineUiSmoke Windows и Linux GTK PASS: реальный диалог, переходы мВ/Ом/мкстрн/В, немедленная смена k;b, сохранение диапазона и ADC-объекта, зарегистрированная ГХ тока. Исходники: UI/uTagSettingsDialog.pas, Device/mic185/uRecorderMic185DataSource.pas. Приборная интерактивная проверка не выполнялась; существующее требование Stop для смены режима MIC185 в runtime не менялось.
