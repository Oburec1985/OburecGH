# MC-032 autosearch: `MDP socket is not connected`

## Симптом

Автопоиск MC-032 завершался исключением в `TMc201LegacyMdpClient.WriteBytes`,
если один из первых адресов подсети не принимал TCP-соединение.

## Подтверждённая причина

`TMc032Device.TestConnection` создавал временный `fClient`, но при раннем
`Exit` после неудачного `TryConnect` код `FreeAndNil(fClient)` не выполнялся.
Следующая итерация поиска считала этот клиент подключённым и пыталась отправить
`TEST_LOAD` через пустой сокет.

## Исправление

Освобождение временного клиента перенесено в `finally`; оно выполняется при
успехе, ошибке, исключении и раннем выходе.

## Проверка

- Полная сборка `lazbuild -B RecorderLnx.lpi`: OK, exit code 0.
- Ручная проверка на стенде: автопоиск должен пропускать недоступные адреса и
  принять только узел с успешным `TEST_LOAD`.
