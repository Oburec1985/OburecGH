# Pipeline ГХ: компоновка MIC-200 и сквозная чувствительность

## Симптомы

- таблица pipeline перекрывала нижние кнопки на GTK/MIC-200;
- строка сквозной чувствительности могла быть не видна;
- две старые масштабные ГХ сообщались как нелинейная цепочка.

## Причины

Таблица и нижние элементы были привязаны к одной клиентской области абсолютными
координатами. Старые SDB могли хранить масштабный множитель как двухточечную
кусочно-линейную таблицу, а расчёт подписи признавал только явные типы scale и
linear.

## Исправление

Таблица и нижние действия разделены панелями с горизонтальным splitter. Подпись
чувствительности живёт в нижней панели и переносится по словам. При расчёте
подписи двухточечная таблица считается масштабом только если обе точки задают
одну прямую через начало координат; таблица со смещением остаётся нелинейной.

## Проверка

Forced Windows build `RecorderLnx.lpi` завершился с exit code 0. Нужна
визуальная проверка реальных GTK-метрик после следующего Linux deploy.
