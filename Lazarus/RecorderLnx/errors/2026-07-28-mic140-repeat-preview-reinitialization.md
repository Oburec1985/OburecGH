# MIC-140: повторный Preview выполнял холодную инициализацию

## Симптом

Каждый переход в Preview надолго зависал, хотя прибор уже был
проинициализирован и аппаратная конфигурация не менялась.

## Подтверждённая причина

`TRecorderMic140DataSource.Stop` смешивал фазы `Stop` и `Disconnect`:

- закрывал TCP-сессию;
- сбрасывал `fHardwarePrepared`;
- сбрасывал `fConfigured`;
- удалял устройство из реестра live-сессий.

Следующий Preview поэтому снова выполнял полный `Connect -> Init -> Configure`
с обязательными BIOS-задержками MIC-140.

Команда UI «Сброс устройства» при этом не сбрасывала устройство и не
инвалидировала конфигурацию — она лишь повторяла проверку связи.

## Исправление

- Обычный `Stop` теперь останавливает только scan/worker и оставляет устройство
  в состоянии `rdsProgrammed`.
- TCP-сессия закрывается в деструкторе источника либо при явном Reset.
- Перед повторным использованием подготовленной сессии выполняется
  `IRecorderDevice.TestLink`.
- При потере связи источник помечается offline и не запускается.
- В универсальный реестр live-устройств добавлен запрос Reset. MIC-140
  потребляет его в `PrepareHardware`, сбрасывает признаки готовности и выполняет
  полный жизненный цикл заново.

## Проверка

- `lazbuild -B RecorderLnx.lpi`: успешно.
- Выполнен один процесс
  `RecorderLnx.exe --preview-seconds=4 --preview-cycles=2`.
- В логе: один `transport connected`, один `initialized`, один `programmed`,
  два перехода `Stop -> Preview` и два `Preview -> Stop`.
- Первый Preview опубликовал 81 блок, второй Preview — 81 блок. Второй цикл
  начался примерно через 0,3 с после Stop без повторного Init/Configure.
- Требуемый runtime-инвариант зафиксирован правилом
  `RLNX_DEVICE_CONFIG_DIRTY_2026_07_28`.

## Оставшийся риск

Изменение аппаратной конфигурации сейчас может пересоздавать runtime-источник.
Для полного сохранения Init между пересозданиями модель устройства следует
отделить по времени жизни от модели источника данных.

## Защита диалога настроек

- Диалог возвращает отдельный признак `DataSourcesChanged`.
- Простое открытие и закрытие через OK больше не очищает `DataSources` и не
  запускает тяжёлый `Init/Configure`.
- Признак устанавливается при добавлении/удалении устройства, изменении его
  аппаратной настройки, состава каналов или источника Mera.
- На входе и выходе из диалога выполняется `TestLink` существующих live-сессий.
  Успешный TEST сохраняет текущую конфигурацию, неуспешный помечает источник
  offline; такой MIC-140 не включается в опрос до явного Reset.
