# Цифровой индикатор возвращался к MemTag

## Симптом

После выбора другого тега и нажатия OK цифровой индикатор отображался, но при
повторном открытии настроек в списке снова был выбран `MemTag`.

## Корневая причина

`TComponentSettingsDialog.StoreToComponent` записывал только `TagName`.
Сохраненный ранее `TagId` продолжал указывать на `MemTag`. Механизм разрешения
ссылок корректно считает ID приоритетным и поэтому возвращал старое имя.

## Исправление

При выборе объекта `TRecorderTag` диалог одновременно записывает его `Id` и
`Name`. Для текстового имени выполняется поиск в реестре; если тег не найден,
`TagId` сбрасывается в 0, чтобы старый ID не мог перекрыть новое имя.

## Проверка

Полная пересборка `RecorderLnx.lpi` завершилась с exit code 0. Инвариант
закреплен правилом `RLNX_TAG_REF_PAIR_2026_07_16`.
