# OPC UA: удаление группы используемых каналов

## Симптом

При выборе контейнерного узла дерева используемых каналов и нажатии Delete
возникало исключение, а после добавления или удаления дерево полностью
разворачивалось и пользователь терял текущую ветвь.

## Причина

Контейнерные узлы не имеют Data, поэтому прежний обработчик умел удалить только
выбранный лист. Затем RebuildUsedTree освобождал owning-список fUsedItems до
очистки TreeNode, оставляя на время перестройки висячие ссылки в TreeNode.Data.
Завершающий FullExpand принудительно уничтожил пользовательское состояние.

## Исправление

- Для выбранного контейнера рекурсивно собираются NodeId всех дочерних листьев,
  после чего строки модели удаляются снизу вверх.
- При перестройке сначала очищаются TreeNode, затем fUsedItems.
- Раскрытые, выделенные, текущий и верхний видимый узлы сохраняются по стабильным
  ключам и восстанавливаются; FullExpand удалён.

## Проверка

Forced Windows-сборка RecorderLnx завершилась с exit code 0. Интерактивный
сценарий Delete на группе остаётся проверить в UI.

Правило предотвращения: `RLNX_TREE_DATA_LIFETIME_AND_VIEW_STATE_2026_09_29`.
