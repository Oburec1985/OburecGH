# 2026-09-29 — медленный импорт общей таблицы каналов ODS

## Симптом

Импорт `recorder_tags_v02.ods` на KIP-1 и KIP-2 выполнялся неприемлемо долго.

## Подтверждённая причина

- В файле 1237 строк, но LibreOffice записал пустой повторяющийся хвост до
  16384-го столбца (`table:number-columns-repeated="16365"`).
- Импортёр повторно искал необязательные заголовки для каждой строки и каждый
  раз проходил этот ложный диапазон. Получалось около 100 миллионов чтений
  пустых ячеек.
- Одинаковая именованная ГХ из `Scales` повторно загружалась из БДГХ для каждого
  канала.

## Исправление

- Поиск заголовков ограничен первыми 256 столбцами и выполняется один раз.
- Разбор строк использует готовую карту колонок.
- Список БДГХ загружается лениво, а каждая использованная именованная ГХ
  импортируется в реестр один раз за проход таблицы.

## Проверка

- Исходный ODS проверен непосредственно: 1237 строк, максимальный повтор
  столбцов 16365.
- Forced Win64 build `RecorderLnx.lpi` завершён с exit code 0.
