# Lazarus VM сообщал об отсутствующем LzrObrPack.lpk

## Симптом

При запуске Lazarus в VM Atra появлялось сообщение: пакет `LzrObrPack`
установлен, но корректный файл пакета `.lpk` не найден; IDE создавала
неработающий пакет-пустышку.

## Причина

Ярлык запускает IDE с `--pcp=/home/user/.lazarus_work`. Пакет был встроен в
`staticpackages.inc` этого профиля, однако ссылка на `.lpk` находилась только
в `/home/user/.lazarus/packagefiles.xml`. Установочный скрипт не передавал
`--pcp`, поэтому регистрировал пакет в профиле по умолчанию, отличном от
рабочего.

## Исправление

- Существующий `.lpk` зарегистрирован командой `lazbuild --add-package-link`
  в `/home/user/.lazarus_work`.
- `install_lzrobrpack_linux.sh` теперь по умолчанию использует рабочий профиль
  и передаёт его во все вызовы `lazbuild`; путь можно переопределить аргументом.
- Инструкция VM исправлена: контрольные пути относятся к `.lazarus_work`.

## Проверка

`packagefiles.xml` рабочего профиля содержит точный путь
`/mnt/win_share/OburecGH/Lazarus/SharedUtils/components/chart_lzr/lzrObrPack.lpk`.
Forced-сборка пакета этим профилем завершилась с exit code 0: 11058 строк,
2 предупреждения, ошибок нет. Открытую IDE не перезапускали, чтобы не потерять
возможные несохранённые изменения; исправление вступит в силу при следующем
запуске.
