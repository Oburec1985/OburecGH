# Сброс X времени при переключении ударов

Симптом: суженная развёртка времени возвращается к полной при выборе удара.
Предыдущая защита восстанавливала X только при ZoomedX=True; автоматический
FitTimePage каждый раз пересчитывал обе координаты. Тест с установленным
ZoomedX=True проходил, но не покрывал фактические узкие границы без этого флага.

Воспроизведение: route-spinner-only, установить .005..017, снять ZoomedX,
сменить ImpactIndex. До исправления exit=1: actual X bounds not preserved.

Исправление: полный fit только при первичной инициализации диапазона либо
явном пользовательском сбросе. При смене удара FitZoomY; уже существующие X
сохраняются независимо от флага и количества ударов. Пустая презентация не
считается повторной инициализацией. Явный double-click по времени по-прежнему
вызывает FitTimePage.

Проверка: route-spinner-only покрывает оба состояния флага, переход через
пустые данные и сохранение явно восстановленного полного диапазона.
Forced-сборка RecorderLnx-time-x-lock.exe успешна.
Ограничение: реальный пользовательский сеанс с измерительным оборудованием
не запускался; проверен переход состояний настоящего LCL view.
