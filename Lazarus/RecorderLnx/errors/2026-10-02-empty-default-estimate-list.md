# Пустой список оценки по умолчанию в свойствах тега

## Симптом

В свойствах `GenSignal_065` на вкладке «Дополнительно» были доступны галки
вычисляемых оценок, но комбобокс «Оценка по умолчанию» оставался пустым.

## Причина

После переноса диалога на LFM код сопоставлял галки с
`TRecorderTagEstimateKind` и умел читать/сохранять выбранный элемент, однако
ни LFM, ни конструктор не заполняли `fDefaultEstimateCombo.Items`. Ошибка была
общей для всех типов тегов, а не только для генератора сигналов.

## Исправление

Добавлен единый `FillDefaultEstimateChoices`. Он заполняет список всеми
восемью поддерживаемыми оценками в порядке enum, сохраняет kind в `Objects` и
использует те же подписи, что у галок. Существующий обработчик выбора включает
расчёт выбранной оценки.

## Проверка

- Принудительная сборка скомпилировала изменённый диалог и все исходники.
- Штатная линковка остановилась только на занятом запущенным приложением
  `RecorderLnx.exe` (Windows error 5).
- Повторная полная компиляция и линковка в отдельный
  `RecorderLnx-default-estimate-verify.exe` завершилась с exit code 0.
