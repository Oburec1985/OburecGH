# Firebird: уведомление отладчика при запуске

## Наблюдение

На старте проекта `test185_149` Lazarus показал first-chance `EIBDatabaseError`
из `TIBConnection.DoInternalConnect`: `Error occurred during login, please
check server firebird.log for details`.

## Проверенные факты

- В проектном `sql-db.ini` SQLdb включена. Глобальный `app.ini` указывает
  `192.168.9.66:3050`, Firebird `recorderlnx.fdb`.
- `TRecorderSqlDbRuntime.RunWriter` сначала проверяет TCP, затем открывает БД.
  Ошибка открытия ловится и переводит SQL runtime в `rsrsError`, запись идёт
  в журнал. Но отладчик останавливается раньше обработчика, на first-chance.
- После снимка удалённый порт `192.168.9.66:3050` не отвечал в диагностическом
  вызове `Test-NetConnection`; повторить именно отказ входа сейчас нельзя.
- Локальный `firebird.log` относится к локальному серверу и не объясняет
  ответ удалённого сервера `.66`. В `LogWindows.log` запись оборвалась сразу
  после загрузки проекта, до сообщения от SQL writer.

## Вывод и следующий шаг

Отказ входа сообщает удалённый Firebird: требуются его `firebird.log` и
проверка действующих учётных данных/параметров аутентификации. Не менять
пароль или файл БД на основании одного first-chance уведомления. После
`Продолжить` проверить в журнале `SQL database disabled` и что основное
приложение продолжает работать. Причина серверного отказа не установлена.
