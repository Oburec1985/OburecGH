# Редактирование и экспорт канальной ГХ

## Симптом

Редактор менял объект общего реестра непосредственно. После переименования
часть тегов продолжала хранить старое имя и при следующем открытии появлялось
сообщение «ГХ не найдена в реестре». Нажатие Cancel после Apply внутри
редактора также не гарантировало откат.

## Причина

Тег хранит pipeline как список имён, а сами ГХ принадлежат общему проектному
реестру. У реестра не было единой операции изменения ГХ и переноса ссылок;
форма редактировала live-объект. SDB-модуль поддерживал только импорт, поэтому
иконка весов не могла выполнять отдельный безопасный экспорт.

## Исправление

- Редактируется глубокая копия. После OK пользователь выбирает общую правку
  либо локальную копию для конечной ГХ pipeline текущего тега.
- Общая операция проверяет конфликт имени и переносит ссылки всех тегов.
- Весы открывают БДГХ в режиме выбора папки. Табличная ГХ экспортируется в
  XML/CSV, а тензокалькуляторная — в JSON с полной моделью и `ModuleData`;
  существующая запись заменяется только после подтверждения.
- Запись использует временные файлы и поэтапный rollback. При overwrite
  загружается исходный property bag, поэтому неизвестные metadata сохраняются.
- Тензометрическая формула не дискретизируется: JSON загружается обратно с
  исходным типом, коэффициентами и настройками тензокалькулятора.
- Просмотрщик больше не трактует strain как пустую таблицу. Он показывает
  параметры `ModuleData`, рабочую формулу и строит график по физическому
  входному диапазону тензокалькулятора.
- Настройка strain вынесена в общий frame и встроена в БДГХ. Правится clone;
  кнопка сохранения обновляет JSON по исходному ключу через temp/backup/verify.
  Импортированное имя больше не содержит путь БДГХ.

## Проверка

- Forced build полной Windows-цели в отдельный executable: exit 0.
- `git diff --check`: exit 0.
- Командное review обнаружило опасный безусловный rollback; он заменён
  признаками фактической установки каждого нового файла.

## Остаточный риск

Автоматического UI-теста диалогов в проекте нет. Нужен ручной сценарий:
переименование общей ГХ, локальная копия, Cancel, экспорт в новую папку,
подтверждённая замена и отказ записи в read-only БДГХ.

## Уточнение UX

Удалён промежуточный вопрос «редактировать или настраивать цепочку». При одной
ГХ редактор открывается сразу. При нескольких показывается read-only список
ступеней текущего pipeline; выбранный индекс передаётся редактору, а локальная
копия заменяет именно эту позицию. Сборка полной Windows-цели — exit 0.
