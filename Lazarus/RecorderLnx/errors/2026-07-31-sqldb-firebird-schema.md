# Создание схемы SQLdb в Firebird

## Симптом

После нажатия «Проверить и создать БД» новый файл Firebird создавался, но
подготовка запроса завершалась ошибкой `SQL error -204: Table unknown SCHEMA_INFO`.

## Причины

1. Запрос к первой таблице выполнялся в той же транзакции, что и DDL. Для
   публикации новых метаданных Firebird требуется граница транзакции.
2. После исправления транзакции выявился второй дефект: уникальный индекс на
   `storage_key varchar(1024)` превышал допустимый размер ключа Firebird/UTF-8.

## Исправление и проверка

- После создания таблиц выполняется полный `COMMIT` и старт новой транзакции.
- Индексируемый `storage_key` ограничен 500 символами (не более 2000 байт UTF-8).
- Проверка выполнена через настоящий `TRecorderSqlDbRepository` на выбранной
  базе `C:\Mera Files\SQLdb\recorderlnx.fdb`: `SCHEMA_VERSION=1`,
  `SCHEMA_INFO_ROWS=1`.
- Полная сборка `RecorderLnx.lpi` завершилась с exit code 0.
