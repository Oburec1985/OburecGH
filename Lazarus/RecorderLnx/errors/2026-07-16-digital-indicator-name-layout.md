# Имя цифрового индикатора не переносилось и не скрывалось

## Симптом

Длинное имя тега обрезало значение цифрового индикатора. В диалоге отсутствовал рабочий и сохраняемый режим «Не отображать имя».

## Причина

`ShowNameMode` существовал в модели, но отрисовка всегда формировала одну строку `имя + значение`. В диалоге два пункта имели одинаковую подпись «Скрыть имя», а формат проекта не сохранял `ShowNameMode`.

## Исправление

- Автоматический режим измеряет ширину имени текущим шрифтом и, если имя шире индикатора, переносит значение целиком на следующую строку.
- Режим `tvnmNone` выводит только значение; режим `tvnmLeft` сохраняет одну строку.
- Диалог содержит однозначные пункты «Не отображать имя», «Автоматически», «Имя слева».
- `ShowNameMode` записывается в `.gui.ini` и безопасно читается с проверкой диапазона enum.
- Отрисовка применяет сохранённые формат и параметры шрифта компонента.

## Правило

`RLNX_VISUAL_SETTING_FULL_CHAIN_2026_07_16`: настройки визуального компонента проверять по полной цепочке UI–модель–отрисовка–сериализация.

## Проверка

Полная сборка `RecorderLnx.lpi` завершилась с exit code 0.
