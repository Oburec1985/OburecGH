# 2026-09-11 — импорт Scales выполнялся старым EXE

## Симптом

Из `recorder_tags_v02.ods` импортировались новые имена каналов, но не
назначалась существующая в БДГХ калибровка `StrainГХ`.

## Подтверждённые факты

- В ODS есть колонка `Scales`; для каналов MIC-185 она содержит `StrainГХ`.
- БДГХ содержит `C:\Mera Files\SDB\Strains\StrainГХ.json`.
- Изолированный запуск актуального `ImportRecorderTagsFromTable` на строке
  `147-1` дал: имя `1Е1`, одна ГХ `StrainГХ`, `ChannelCalibrationEnabled=True`,
  тип `rckStrain`, `K1=5555.416667`, предупреждений нет.
- Установленный `C:\Program Files (x86)\Mera\RecorderLnx\RecorderLnx.exe`
  датирован 2026-07-29 и не содержит новую колонку `Scales`.

## Причина

Старый импортёр знает прежние столбцы, поэтому применяет переименование, но
игнорирует неизвестный `Scales`. Это точно совпадает с наблюдаемым результатом.

## Действие и проверка

Актуальный исходный код и Win64-сборка проверены на пользовательском ODS.
Автоматическая замена EXE в Program Files отклонена Windows (`Access denied`),
поэтому установленную копию требуется обновить с повышенными правами.
