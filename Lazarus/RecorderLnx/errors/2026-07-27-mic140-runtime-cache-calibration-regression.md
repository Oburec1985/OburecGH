# MIC-140: регрессия термопарного пересчёта при оптимизации RunTime

## Симптом

После исключения строковых поисков из обработки аппаратного блока показание
термопары изменилось примерно с `-100 °C` до `-87 °C`, хотя настройки канала и
состояние прибора не менялись.

## Причина

При восстановлении прежней логики компенсации холодного спая строки
инициализации `lCjcOffsetC` оказались после завершающего `end.` юнита.
Компилятор FPC не сообщил об этом как об ошибке, поэтому функция использовала
неинициализированную локальную переменную.

Дополнительно при оптимизации важно различать два вида блоков:

- коды АЦП, для которых `TRecorderTag` ещё должен применить аппаратную ГХ;
- уже пересчитанные значения, которые нельзя преобразовывать повторно.

## Исправление

- Инициализация `lCjcOffsetC := 0.0` и чтение `CjcTemperOffsetC` возвращены
  внутрь `Mic140TransformThermocoupleChannelSample`.
- Для температурных входов `TIn` сохранён вызов `AddBlockSamples(..., False)`,
  потому что входной блок содержит коды АЦП.
- Для уже пересчитанного термопарного канала используется
  `AddBlockSamples(..., True)`.
- Решения о включении аппаратной ГХ, термокомпенсации и выборе канала ХТС
  оставлены в прежнем проверенном тракте.

## Правило предотвращения

`RLNX_RUNTIME_CALIBRATION_EQUIVALENCE_2026_07_27`

Оптимизация горячего тракта не должна менять порядок и количество физических
преобразований. Перед заменой API публикации необходимо явно записать для
каждого массива его состояние: `raw ADC`, `hardware calibrated`, `CJC
corrected`, `final engineering value`. Флаг `values already transformed`
задаётся только по этому состоянию, а не ради ускорения.

После изменения калибровочного тракта обязательна численная проверка одного и
того же канала до/после по четырём контрольным величинам:

1. исходный код АЦП;
2. значение после аппаратной ГХ;
3. температура холодного спая и её поправка;
4. итоговое значение тега.

Также при ревью Pascal-юнита необходимо проверять, что после финального `end.`
нет текста: FPC способен не диагностировать такой ошибочный хвост.
