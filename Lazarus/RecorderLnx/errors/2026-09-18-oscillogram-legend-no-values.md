# Легенда осциллограммы не показывала значения

## Симптом

После появления нижней легенды в ней были только цвет и имя канала. При движении X-курсоров и обновлении сигнала показания не менялись. Нажатые кнопки панели визуально не выделялись.

## Подтверждённая причина

`UpdateLegend` создавал подписи только при конфигурации компонента и записывал в них одно имя. В обработчике движения курсора и в `Refresh` обновления легенды не было. `TToolButton` рисовался системной темой без гарантированного цветного фона для `Down`.

## Исправление

Подписи легенды создаются при изменении состава линий; при новом кадре и движении курсора обновляется только их текст. Значение берётся из уже построенной серии: последнее без курсоров, линейная интерполяция в X1/X2 и разность при двух курсорах; отсутствующие данные показываются `-`. Для кнопок назначен собственный обработчик отрисовки с голубым фоном активного состояния.

## Проверка и риск

`lazbuild -B RecorderLnx.lpi` на Windows — exit 0, штатный EXE заменён. Сценарий с реальным сигналом в GUI не проверен; оператору нужно подтвердить подписи после движения курсоров и нового кадра.
