# Иконки сохранения с розовым фоном в Linux

## Симптом

В Linux кнопки сохранения конфигурации отличались от Windows и показывали
фуксиевый фон.

## Причина

Windows загружал BMP оригинального Recorder по абсолютному пути рабочего
компьютера. В Linux путь отсутствовал, поэтому код заменял встроенные в LFM
эталонные изображения нарисованным fallback. Маска его прозрачности
обрабатывалась LCL иначе и фуксия становилась видимым фоном.

## Исправление

Если внешний BMP недоступен, `RefreshSaveConfigIcons` больше не заменяет
встроенную картинку ImageList. Поэтому обе платформы используют одинаковый
эталон из формы; внешний ресурс применяется только после успешной загрузки.

## Проверка

- Полная сборка Windows `RecorderLnx.lpi`: exit code 0.
- Полная сборка Linux в Astra VM: exit code 0.
