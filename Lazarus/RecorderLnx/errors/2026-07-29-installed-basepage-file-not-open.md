# Установленная версия: File not open при переходе на BasePage

## Симптом

После установки в `C:\Program Files (x86)\Mera\RecorderLnx`, добавления MIC-140 и
перехода на BasePage появлялось сообщение `File not open`.

## Причина

OglChart пытался создать диагностические файлы рядом с EXE. Обычный пользователь
не имеет права записи в Program Files. После неудачного `Rewrite/Append` код
безусловно вызывал `CloseFile`, поэтому исходный отказ доступа скрывался вторичной
ошибкой `File not open`.

Основной логгер также содержал отладочную подмену пути `..\..\LogWindows.log`, из-за
чего фактическое расположение журнала зависело от структуры каталога запуска.

## Исправление

- Все служебные пути RecorderLnx вычисляются через `RecorderServicePath`:
  `<MeraFiles>\RecorderLnx`.
- `LogWindows.log`, `LogLinux.log` и журналы OglChart перенесены туда.
- Ошибка диагностической записи больше не выходит в рабочий UI.
- Подробная трассировка OglChart выключена по умолчанию.
- Установщику не требуется выдавать право записи в каталог приложения.

## Проверка

- Полная сборка `RecorderLnx.lpi` прошла с exit code 0.
- Тестовый запуск создал/обновил служебные файлы в
  `C:\Mera Files\RecorderLnx`, а не в каталоге EXE.
