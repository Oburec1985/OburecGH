# Нормальные теги стали серыми после добавления контроля диапазона

## Симптом

После добавления контроля допустимого диапазона серым отображались все строки цифровой формы, включая `CpuUsage` со значением внутри диапазона.

## Причина

В `TRecorderAlarmEngine.GetTagAlarmColor` серый цвет был ошибочно назначен значением результата по умолчанию. Поэтому серым становилось состояние без активной уставки, независимо от результата проверки диапазона.

## Исправление

Нейтральное состояние снова возвращает служебное значение `0`. Цвет `$808080` возвращается только при `OutOfRange=True`.

## Проверка

Полная сборка `RecorderLnx_verify.exe` завершена с exit code 0. Штатный EXE не заменён, потому что запущен RecorderLnx PID 13680.
