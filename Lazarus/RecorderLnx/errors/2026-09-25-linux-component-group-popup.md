# Linux: меню группы компонентов закрывалось в момент открытия

## Симптом

В Windows кнопка группы компонентов (например, «Графики») открывала список,
а в Linux/GTK визуально ничего не происходило.

## Причина

`TPopupMenu.PopUp` вызывался синхронно из `TSpeedButton.OnClick`. На GTK событие
клика ещё находится внутри обработки кнопки мыши, поэтому тот же отпуск мыши,
который завершает клик, мог немедленно закрыть только что открытое меню. Иконка
поля ввода и разделение осциллограммы с плагинным осциллографом причиной не были.

## Исправление

В `uRecorderComponentToolGroup` открытие одиночного и группового меню перенесено
в `Application.QueueAsyncCall`. Меню создаётся после завершения текущего события
мыши, одинаково для Windows и GTK.

## Проверка и правило

Forced-сборки Windows и Linux завершились с exit code 0. Версия 0.1.71 собрана
в DEB и установлена на MIC-200 и четыре KIP (5/5).

Меню, инициируемое нажатием toolbar/speed-button, на GTK нельзя открывать
синхронно из `OnClick`: использовать отложенный вызов после завершения события
мыши и проверять поведение на реальном GTK.
