# SQL-тренд: live reload сбрасывает мышиный zoom

## Симптом

После выделения области мышью SQL-тренд примерно через период фонового опроса
возвращался к полному временному диапазону.

## Подтверждённые факты

- Рамка zoom корректно изменяла `fFromUtc`/`fToUtc`.
- Таймер режима «от даты по текущую дату» запускал инкрементальную загрузку.
- `AcceptLoad` после каждого успешного ответа безусловно снова назначал
  viewport от `Component.FromUtc` до времени ответа.
- Сами данные и полный диапазон `fFullFromUtc`/`fFullToUtc` обновлялись
  независимо от видимого диапазона.

## Причина

Полный диапазон загруженных данных и пользовательский X-viewport не имели
отдельного состояния. Логика live auto-follow считала любой показанный диапазон
автоматическим и перезаписывала результат ручного zoom/pan.

## Исправление

- Добавлен признак `fManualXRange`.
- Горизонтальный zoom и фактический X-pan включают ручной режим.
- Live reload продолжает подгружать и объединять новые точки, но не меняет
  ручной viewport.
- Кнопка/двойной щелчок «Весь график» также считаются явным пользовательским
  viewport и сохраняются при последующих обновлениях.
- Auto-follow включается при первичной настройке/перезагрузке компонента, а не
  вслед за пользовательским действием.

## Дополнение: двойной щелчок

Повторная проверка на живом интерфейсе показала отдельный путь: `DblClick`
вызывал `ResetZoomClick`, а тот снимал признак ручного X-диапазона. Поэтому
пересчитанный по данным масштаб жил только до следующего SQL-ответа. Снятие
ручного режима из `ResetZoomClick` удалено.

## Проверка

- Forced-компиляция исходников прошла; штатная линковка остановилась с
  `error 5`, потому что запущенный RecorderLnx удерживает основной EXE.
- Полная forced-сборка с выводом в `RecorderLnx_zoom_verify.exe` завершилась с
  exit code 0.
- `git diff --check` для изменённого модуля ошибок не обнаружил.

## Остаточный риск

Нужно визуально подтвердить поведение на живой SQL БД: zoom должен пережить
несколько периодов обновления, а «Весь график» — снова включить auto-follow.
