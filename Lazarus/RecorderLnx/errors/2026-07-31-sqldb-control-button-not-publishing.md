# Кнопка SQL DB не публиковала управляющий тег

## Симптом

Кнопка мнемосхемы в режиме фиксации не меняла `SqlDbRecordEnabled`, индикатор
оставался равным нулю. Чекбокс SQL DB включал менеджер, но тег также оставался 0.

## Подтверждённые причины

1. При переключении edit mode контроллер переиспользовал визуальный `TButton` и
   оставлял на нём mouse handlers редактора. Runtime click не доставлялся.
2. `cbSqlDbRecordingChange` вызывал только `SetRecordingEnabled` и не публиковал
   состояние в управляющий тег.

## Исправление

Смена edit mode принудительно пересоздаёт визуальные controls страницы, поэтому
кнопка получает обработчики соответствующего режима. После успешного ручного
переключения SQL DB состояние публикуется в `SqlDbRecordEnabled` через общий
`PublishSqlDbControlState`; тот же путь используется при инициализации.

## Проверка

Полная сборка во временный `RecorderLnx_verify.exe` завершилась с exit code 0.
Ручная проверка обоих направлений остаётся после остановки текущего EXE и запуска
новой сборки.
