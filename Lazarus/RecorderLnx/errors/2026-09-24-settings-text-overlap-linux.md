# На Linux подписи в общих настройках перекрывали поля

## Симптом

На MIC-200 в диалоге `Настройка` подписи `Период обновления`, элементы
`Условия старта записи` и соседние поля частично накладывались друг на друга.
На Windows дефект мог не проявляться из-за другой ширины шрифта.

## Причина

Связанные элементы формы были расставлены независимыми абсолютными
координатами. Ширина русской подписи и radio button зависит от системного
шрифта, DPI и widgetset, поэтому фиксированная координата следующего элемента
не гарантировала зазор на GTK/Linux.

## Исправление

После создания формы зависимые элементы переставляются относительно
фактической ширины предыдущего элемента с фиксированным зазором. Это сделано
для периодов обновления, условий старта и условий останова. Бизнес-логика и
значения настроек не менялись.

## Проверка

- forced Windows build `RecorderLnx.lpi`: exit code 0;
- проверена компиляция полного проекта с актуальной LFM и динамической
  инициализацией формы.

Окончательная визуальная проверка GTK/DPI выполняется после общей Linux-сборки
и установки на MIC-200.

## Правило

Не размещать второй элемент строки по абсолютному `Left`, если первый содержит
локализованный текст. Использовать anchors/layout либо вычислять позицию по
`Left + Width + Gap` после назначения Caption и шрифта.
