# FRF: вход в редактор сцены после привязки

Симптом: `Resource TRecorder3dFrfModifierFrame not found` при открытии редактора
сцены. Первопричина: новый наследник TFrame вызывал Create, который загружает
ресурс класса, но соседнего LFM и директивы ресурса не было. Компиляция этого
не обнаруживает; требуется фактическое создание frame.

Исправление: добавлены соседний LFM и `{$R *.lfm}`; статический TStringGrid
перенесён в LFM. В UI smoke добавлено реальное создание/освобождение frame.

Правило предотвращения: каждый TForm/TFrame создаваемый стандартным Create
должен иметь LFM; успешная сборка не заменяет тест создания ресурса.

Повторная проверка реального редактора сцены обнаружила Duplicate name:
оба экземпляра одного FRF frame наследовали одинаковое имя из LFM. Теперь
первый переименовывается frIntensity перед созданием второго frOscillation.
UI smoke создаёт целиком редактор сцены и меняет размер шрифта, RESULT passed.
