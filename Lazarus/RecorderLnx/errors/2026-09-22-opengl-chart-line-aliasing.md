# Ступенчатые линии OpenGL chart

## Симптом

На пологих линиях осциллограммы видна регулярная однопиксельная «лесенка».

## Подтверждённые факты

- Осциллограмма передаёт в chart исходные `Double` без округления.
- `uOglChartLineHelper` преобразует координаты в дробные `Single` и рисует
  `GL_LINE_STRIP` с шириной 2.3.
- До исправления контекст не запрашивал multisampling, а рендерер не включал
  `GL_LINE_SMOOTH`; blending сам по себе края линии не сглаживает.
- Аналогичная ступенчатость возможна и в GDI, поэтому она не доказывает
  дискретизацию измерительных данных.

## Исправление

`TOglChart` запрашивает `MultiSampling = 4` до создания контекста. Рендерер
включает `GL_MULTISAMPLE`, `GL_LINE_SMOOTH` и `GL_NICEST`. Если платформа не
может создать multisample framebuffer, LCL повторяет создание без него, а
сглаживание линий остаётся резервным путём.

## Проверка

- chart_lzr успешно скомпилирован.
- Полная forced-сборка RecorderLnx в отдельный EXE завершилась с exit code 0.
- Визуальная проверка Windows/Linux пока не выполнена; итог зависит от качества
  реализации legacy OpenGL line smoothing конкретным драйвером.
