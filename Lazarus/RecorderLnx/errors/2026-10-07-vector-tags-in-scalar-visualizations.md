# Векторные теги не выбирались в скалярной визуализации

## Симптом

Модификатор 3D «Цвета вершин» скрывал векторные теги. Другие скалярные
визуализации читали последний отсчёт напрямую и не использовали рассчитанные
скалярные оценки векторного тега.

## Причина

- `uRecorder3dVertexColorModifierFrame` явно пропускал `IsVector`.
- `uRecorder3dVertexColorAdapter` повторно отвергал векторный тег.
- Единого контракта чтения тега как скалярного значения не было.

## Исправление

Добавлен `RecorderTryReadScalarValue`: scalar сохраняет прежнее поведение
последнего значения, vector возвращает default или выбранную оценку. На этот
контракт переведены scalar-read визуализации. Для цветового якоря сохраняются
`EstimateKind` и `UseDefaultEstimate`; write-контролы не менялись и продолжают
допускать только `ExternalWriteAllowed`.
Обычный компонент `TagValue` также сохраняет эти настройки. Редактор цветового
якоря показывает только включённые оценки, отмечает сохранённую недоступную
оценку и выводит строку состояния для отсутствующей вершины, градиента, тега
или данных оценки.

## Проверка

- `RecorderFormModelTest`: round-trip настроек якоря и Mean/RMS vector estimate.
- forced build `RecorderFormModelTest.lpi` и запуск теста: успешно.
- forced build `RecorderLnx.lpi`: успешно.
