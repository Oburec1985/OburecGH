# MIC-185: четырёхкратная ошибка пересчёта Ом в микрострейны

## Симптом

При базовом сопротивлении 120 Ом, тензочувствительности 2,3 и показании
прибора 0,272 Ом режим «мкстрн» показывал около 4000 вместо примерно 1000.

## Причина

Режим «Ом» MIC-185 уже возвращает фактическое изменение сопротивления `dR`.
Recorder повторно применял обратный мостовой коэффициент `4/2/1` для
тензометра, полумоста и моста. Для тензометра это учетверяло результат.

## Исправление

Режим «Ом» оставлен независимым от схемы. Для режима «мкстрн» применяется
коэффициент числа активных тензорезисторов `1 / 0,5 / 0,25`, после чего
используется формула `epsilon = dR / (R0 * k) * schemeCoeff * 1e6`.
Контрольная точка для тензометра: `0,272 / (120 * 2,3) * 1e6 = 985,507`.

## Проверка

- forced Win64 build: exit code 0;
- forced Linux build в Astra VM: exit code 0, missing libraries: none;
- DEB 0.1.109 собран из свежего ELF;
- 0.1.109 установлен и подтвержден на 192.168.9.17, .45, .66 и .85.

## Правило

Не применять мостовой коэффициент при показе сопротивления. При переводе
фактического `dR` в деформацию коэффициент схемы отражает число активных
тензорезисторов и уменьшает результат (`1/N`), а не увеличивает его (`N`).

## Дополнение: вход «Ом» встроенной Strain-ГХ

В генераторе Strain-ГХ ветка `rsiOhm` ошибочно вычисляла вход как коэффициент
разбаланса, умноженный на эквивалентное сопротивление моста. Для показания
MIC-185 в Ом это повторно учитывало четверть-мост и давало около 4000 мкстрн
для контрольных 0,24 Ом.

Исправлено: вход «Ом» принимается как уже измеренное прибором изменение
сопротивления `dR = R0 * K * epsilon`. Контрольная точка 0,24 Ом, 120 Ом,
K=2 теперь даёт 1000 мкстрн. Схема включения продолжает учитываться для
электрических входов мВ и мВ/В.

Версия 0.1.110 принудительно собрана под Win64 и Linux; DEB установлен на
KIP-1 `.17`, KIP-2 `.45`, KIP-3 `.66` и KIP-4 `.85` (4/4).

## Уточнение электрического входа при питании током

Вход `мВ` при выбранном питании током означает изменение падения напряжения
на одиночном тензорезисторе, а не дифференциальный выход моста. Поэтому
используется `dU[мВ] = I[мА] * dR[Ом]` без коэффициента схемы. Контрольная
точка: `3 мА * 0,24 Ом = 0,72 мВ`, затем
`0,72 / 3 / (120 * 2) * 1e6 = 1000 мкстрн`.

Исправление выпущено как 0.1.111; Win64/Linux build успешны, установка на все
четыре KIP подтверждена 4/4.

## Пересчёт сохранённых коэффициентов

Старые проекты сохраняли рассчитанные `Offset/K1/K2`, поэтому после обновления
физической модели продолжали выполнять прежнюю формулу до ручного OK в
редакторе. С версии 0.1.112 коэффициенты Strain-ГХ пересчитываются из
`ModuleData` при загрузке проекта и после подтверждённого изменения параметров.
При открытии редактора черновая формула также пересчитывается для предпросмотра.

0.1.112 собрана под Win64/Linux и установлена на KIP `.17`, `.45`, `.66`,
`.85` — 4/4.
