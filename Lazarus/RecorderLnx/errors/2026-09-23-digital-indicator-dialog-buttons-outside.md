# Кнопки диалога цифрового индикатора оказались за нижней границей

## Симптом

В настройках цифрового индикатора не отображались нижние кнопки подтверждения
и отмены. Остальные поля формы помещались в окно.

## Причина

Диалог создаётся программно через `CreateNew`. Кнопкам назначались anchors
`akBottom` до установки вычисленной `ClientHeight`. При последующем изменении
высоты LCL сохранял расстояние до прежней нижней границы и дополнительно
сдвигал кнопки вниз, за пределы нового клиентского прямоугольника.

## Исправление

Сначала устанавливаются окончательные `ClientHeight` и `MinHeight`, затем
кнопкам назначаются правый и нижний anchors. Начальные координаты больше не
пересчитываются относительно промежуточного размера формы.

## Проверка

- forced Windows-сборка RecorderLnx — exit code 0;
- forced Linux-сборка — exit code 0;
- DEB 0.1.66 установлен на MIC-200: 1 succeeded, 0 failed;
- HostAgent вернул `ready`, RecorderLnx запущен.

## Правило предотвращения

Для программно создаваемых форм сначала задавать окончательный размер и только
после этого включать anchors, зависящие от правой или нижней границы.
