# MC-201: скрыты сервисные кнопки настройки канала

## Симптом

В общем диалоге настройки канала для MC-201 не показывались балансировка,
переход к аппаратным настройкам и чтение аппаратной калибровки, хотя те же
элементы присутствовали для MIC-140/MIC-185.

## Причина

Общий UI определял возможности по текстовому префиксу `SourceId` и содержал
закрытый список моделей. Добавление нового драйвера не расширяло этот список,
поэтому существующие кнопки становились невидимыми.

## Исправление

- в базовый контракт `IRecorderDevice`/`TRecorderDevice` добавлены
  `SupportsDeviceAction` и `ExecuteDeviceAction`;
- драйвер шины MC переопределяет сервисные действия;
- MC-201 подключён к общим обработчикам диалога;
- аппаратная настройка открывает диалог именно того слота MC-201, которому
  принадлежит выбранный канал;
- балансировка маршрутизируется через источник данных и базовый интерфейс
  устройства.

## Правило предотвращения

Общий диалог устройства не должен считать список моделей исчерпывающим.
Новое сервисное действие сначала добавляется в базовый контракт устройства,
затем переопределяется драйвером. Проверка: добавление нового поддерживающего
драйвера не требует нового обработчика кнопки, а полная сборка проекта проходит.

## Ограничение

Для MC-201 сейчас реализована программная балансировка текущего сеанса.
Чтение заводских коэффициентов из flash MC-201 ещё не портировано из старого
Recorder; кнопка подключена к общему вызову и возвращает явное сообщение о
неподдерживаемой операции вместо молчаливого отсутствия действия.
