# Диалог страниц использовал предыдущую строку TStringGrid

## Симптом

После выбора пользовательской страницы `New mnemonic` поле имени продолжало
показывать `Base page`, а кнопка выбора фона оставалась заблокированной.
При выборе встроенной страницы наблюдалось обратное состояние.

## Подтверждённая причина

Событие `TStringGrid.OnSelectCell` приходит с новой строкой в параметре
`aRow` до того, как свойство `TStringGrid.Row` становится новым значением.
Обработчик вызывал `GetSelectedPage`, который читал старое `Row`, поэтому
редактор свойств синхронизировался с предыдущей страницей.

## Исправление

`TFormPagesDialog.SelectCell` получает модель непосредственно по `aRow - 1`
и передаёт её в `UpdatePageEditors`. Чтение `fGrid.Row` в этом событии больше
не используется.

## Проверка

- пользовательская строка передаёт в редактор объект mnemonic page, для неё
  кнопки выбора и очистки фона разрешаются;
- встроенная строка передаёт объект built-in page, для неё кнопки запрещаются;
- полная сборка `RecorderLnx.lpi` завершилась с exit code 0.
