# Привязка SVG-параметра падала при восстановлении edit handlers

## Симптом

При привязке тега `GenSignal_65` к углу стрелки SVG программа останавливалась
в `TFormEditorController.RestoreEditMouseHandlers` на обращении к `Cursor`.

## Причина

Редактор мнемосхемы рекурсивно сохранял обработчики мыши дочерних LCL-контролов
как обычные указатели. Диалог SVG меняет модель сразу, а периодический
`RefreshLive` может пересоздать внутренний контрол изображения ещё до закрытия
диалога. Сохранённый указатель после этого оставался ненулевым, но уже указывал
на освобождённый объект.

## Исправление

`TEditorMouseHandlerState` стал `TComponent` и подписывается на
`FreeNotification` отслеживаемого контрола. При его уничтожении ссылка
обнуляется; восстановление обработчиков пропускает уже удалённое представление.
При штатном восстановлении подписка снимается в деструкторе состояния.

## Проверка

- `run-svg-editor-checks.ps1` — PASS (`SvgParameters` и
  `SvgImageSettingsUiSmoke`).
- Принудительная полная Windows-сборка RecorderLnx — exit code 0, включая
  компиляцию изменённого `uFormEditorController` и линковку приложения.

Живой повтор сценария в уже запущенном экземпляре требует запуска вновь
собранного EXE.
