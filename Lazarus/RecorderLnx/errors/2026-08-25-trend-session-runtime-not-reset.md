# Trend сохранял runtime-состояние между сессиями

## Симптом

После повторного запуска View или Record обычный Trend продолжал показывать
линии предыдущей сессии. Новые точки иногда долго не появлялись.

## Причина

`TRecorderTimeSystem.Start` создаёт новую временную эпоху, и время новых отсчётов
снова начинается около нуля. Буфер тега распознаёт откат времени самостоятельно,
но `TRecorderTrendView` сохранял собственные OGL-очереди, `LastProcessedTime` и
`LastBlockCounter`. Поэтому старые точки оставались видимыми, а новые отсчёты
могли отбрасываться как уже обработанные.

Повторный `Configure` не является границей сессии и в fast path намеренно
переиспользует представление, поэтому очистка там была бы ненадёжной и могла бы
срабатывать при обычном редактировании настроек.

## Исправление

- `TRecorderTrendView.ResetSessionData` очищает только runtime-данные линий;
- текущий `BlockCounter` связанного тега сохраняется как baseline, чтобы до
  прихода новых данных не принять последний блок старой сессии повторно;
- reset вызывается в `StateMachineStateChanged` только для фактических
  `rstStopToView` и `rstStopToRecord`, до `TimeSystem.Start` и запуска источников;
- вызов охватывает созданные скрытые страницы и detached-окна;
- session generation и таблица baseline применяются при последующем создании
  или перестроении Trend, поэтому lazy page не принимает старый блок;
- скрытые контролы очищают данные без redraw, zoom пользователя сохраняется;
- конфигурация линий/осей и SQL Trend остаются неизменными.

## Правило предотвращения

Runtime-курсор потребителя и его локальный графический буфер принадлежат одной
acquisition epoch. При создании новой epoch они должны сбрасываться вместе и до
публикации первого нового блока. Нельзя заменять это очисткой конфигурационной
модели или глобальной историей тегов.

## Проверка

- `lazbuild -B RecorderLnx.lpi`: exit code 0, успешная линковка;
- `git diff --check`: ошибок нет;
- существующий `RecorderStateMachineTest.lpi` сейчас не компилируется: в его
  search path отсутствует каталог с `uRecorderMeraPaths`; production build
  подтверждает компиляцию изменённого state hook;
- ручная матрица: несколько циклов View/Stop/View и Record/Stop/Record, включая
  скрытую страницу и detached-окно; View→Record без Stop не должен очищать Trend.
