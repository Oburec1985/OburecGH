# 2026-11-05 — оси перекрывают настройки линий SQL-тренда

## Симптом

В развёрнутом окне настроек SQL-тренда группа «Оси Y» закрывала нижнюю часть
параметров выбранной линии: видимость, цвет и команды работы с диапазоном.

## Подтверждённая причина

В `uRecorderSqlTrendSettingsDialog.lfm` группа линий имела нижний anchor и
растягивалась по высоте окна. Группа осей одновременно была привязана к низу и
в исходной геометрии начиналась на `Top=352`, хотя группа линий с `Top=50` и
`Height=360` заканчивалась на 410. Секции пересекались уже в исходной форме, а
при изменении высоты перекрытие становилось заметнее.

## Исправление

- Вертикальные группы переведены на верхние anchors и расположены
  последовательно без пересечения: линии 50..410, оси 418..548, время
  556..724.
- Кнопки подтверждения перенесены ниже содержимого.
- У формы включена вертикальная автопрокрутка и уменьшена минимальная высота,
  чтобы все элементы оставались достижимы на экране небольшой высоты.

## Проверка

- `git diff --check` — ошибок нет (только предупреждение LF/CRLF).
- Полная forced Win64-сборка `RecorderLnx.lpi` — exit code 0, 243582 строки.
- Живая визуальная проверка в пользовательской конфигурации остаётся за
  следующим открытием диалога.
