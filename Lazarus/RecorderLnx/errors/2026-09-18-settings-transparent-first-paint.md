# Прозрачное окно настроек при открытии

При нажатии кнопки настроек окно появлялось прозрачным на время первой
отрисовки большой страницы формы.

Перед `ShowModal` форма теперь создаёт оконный handle, включает двойную
буферизацию, один раз показывается и принудительно обновляется, затем
скрывается и открывается модально. Пользователь получает уже подготовленный
первый кадр.

Проверочная сборка `RecorderLnx_settings_prepaint.exe` прошла: 151143 строки,
ошибок компиляции нет. Визуальную проверку нужно повторить в запущенном GUI.
