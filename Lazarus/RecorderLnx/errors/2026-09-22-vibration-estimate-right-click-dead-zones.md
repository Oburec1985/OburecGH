# ПКМ не открывал настройки на частях виброоценки

## Симптом

Редактор компонента открывался правой кнопкой только на незанятых участках
панели виброоценки. На имени/значении, стрелках, кнопке A/V/S и кнопке единиц
ПКМ не работал.

## Причина

LCL не всплывает mouse-события дочернего control к родителю. Контроллер формы
назначал обработчик редактора корневому `TRecorderVibrationEstimateView`, но
его пять дочерних элементов перехватывали `MouseUp`.

## Исправление

Дочерние элементы получили локальный обработчик, который передаёт корневому
view только правый `MouseUp` с пересчитанными координатами. Левые клики не
передаются и продолжают управлять полосой, величиной и единицами.

## Проверка

Полная компиляция Pascal-кода проходит. Финальная линковка штатного EXE пока
невозможна: работающий RecorderLnx удерживает файл назначения (error code 5).
