# MC-032 оставался неактивным при поступающих данных

## Симптом

В дереве аппаратных настроек MC-032 отображался неактивным, хотя Preview уже
получал данные с его MC-201. Сброс удалял отметку ошибки без подтверждения связи.

## Корневая причина

Сохраненная offline-метка проверялась раньше состояния живого устройства и
перекрывала более новое свидетельство `rdsStarted`. Кроме того, `TestLink` мог
послать команду TEST в уже занятую потоковую MDP-сессию и получить ложный отказ.

Повторная трассировка выявила второй дефект lifecycle: штатный `Stop` сохранял
TCP-соединение и состояние `rdsProgrammed`, но удалял устройство из live-реестра.
Повторный `Start` возобновлял данные, не восстанавливая регистрацию. Дерево не
видело рабочий объект и ошибочно открывало второй TCP-сеанс для probe. MC-032
обслуживает один такой сеанс, поэтому отдельный клиент получал timeout.

## Исправление

- работающая сессия имеет приоритет и очищает устаревшую offline-метку;
- MCbus `TestLink` при `rdsStarted` использует активный поток как подтверждение;
- ручной сброс выполняет TEST, сохраняет новую ошибку при отказе и окрашивает
  устройство зеленым только при успехе;
- hint показывает сохраненную причину ошибки, не обращаясь к сети.
- каждый успешный `Start` повторно регистрирует live-устройство;
- штатный `Stop` не удаляет из реестра сохраненную запрограммированную сессию;
  unregister выполняется только при реальном disconnect или уничтожении source.

## Проверка

Полная сборка `RecorderLnx.lpi` с ключом `-B` завершилась с exit code 0.
Инварианты закреплены правилом `RLNX_DEVICE_STATUS_EVIDENCE_2026_07_16`.

Серия стендовых проверок `Mc201ProtocolDebug --cli`: три последовательных запуска
прошли с первой попытки, каждый обнаружил контроллер SN=841 и четыре MC-201
SN=1462/1465/1464/1463. При одновременно запущенном RecorderLnx отдельный CLI
пять раз получил timeout, что подтверждает одноклиентный характер контроллера и
ошибочность второго probe при существующей live-сессии.

## Остаточный риск

Проверка на реальном контроллере нужна для визуального подтверждения смены
иконки и текста hint, но сетевой протокол потокового чтения не изменялся.
