# Линия Лиссажу могла не отображаться

## Симптом

При выбранных X/Y сигналах график Лиссажу оставался пустым либо строился
нестабильно. В настройках длинное описание сигнала скрывало его имя и частоту.

## Причина

Y интерполировался для каждого timestamp X, но выходной буфер выделялся по
`Min(XCount, YCount)`. При большей частоте X число записываемых пар могло
превысить ёмкость массива и повредить геометрию.

## Исправление

- Ёмкость пар соответствует опорной X-выборке.
- Список сигналов стал таблицей коротких имён и частот опроса.
- Двойной щелчок подбирает X/Y по фактическим данным Лиссажу.
- Добавлены независимые режимы линии, точек, главного диаметра, его центра и
  подписи значения. Главный диаметр определяется как максимальная хорда
  выпуклой оболочки Грэхема, как в старом компоненте Лиссажу, и пересчитывается
  только при новых данных. PCA-вариант сохранён отдельно в общей 2D-библиотеке.

## Проверка

`GeometryTests.exe` — passed. Forced Windows-сборка RecorderLnx 0.1.97 —
exit code 0. Ручная визуальная
проверка на живых X/Y сигналах остаётся приёмочным тестом.
