# Недоступный сетевой прибор вызывал исключение при загрузке проекта

## Симптом

При выключенном MIC-140 загрузка проекта останавливалась в отладчике на
`TInetSocket.Create`: восстановление аппаратной калибровки напрямую открывало
TCP-сессию до проверки связи.

## Причина

Путь чтения серийного номера для калибровки обходил штатный `TestLink`.
Кроме того, общий менеджер источников не преобразовывал исключение
`PrepareHardware` в offline-состояние конкретного источника.

## Исправление

MIC-140 теперь выполняет короткий TCP TEST до создания протокольного клиента.
Общий вызов `TestLink` защищён от исключений. Менеджер источников сохраняет
ошибку подготовки, помечает соответствующий `SourceId` offline и не запускает
для него поток; главная форма переносит ошибку в системный журнал.

## Правило

См. `Docs/development-rules.md`, раздел «Недоступное устройство — штатное
состояние».
