# Узкие и мёртвые зоны компонентов в редакторе мнемосхемы

## Симптом

У кнопки в режиме редактирования клики принимала в основном рамка контейнера.
На составных компонентах вложенные labels, grids, panels и toolbar также не
позволяли выбрать, перетащить или открыть настройки компонента.

## Причина

При повторном использовании контрола кнопка сохраняла runtime mouse handlers,
которые намеренно ничего не делают в edit mode. Кроме того, редактор назначал
свои handlers только корневому контролу, а вложенные LCL controls перехватывали
события без всплытия к родителю.

## Исправление

`TFormEditorController` в edit mode рекурсивно назначает обработчики выбора,
drag и открытия свойств всему дереву визуального компонента. Исходные handlers
сохраняются и восстанавливаются до Render, выхода из edit mode и уничтожения
контроллера. Resize определяется относительно общего host-panel, поэтому край
вложенного элемента не принимается за край всего компонента.

## Проверка

Forced Windows build — exit code 0. Linux build — `BUILD_EXIT=0`,
`MISSING_LIBS none`. Версия 0.1.92 установлена на MIC-200.
