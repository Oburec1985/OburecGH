# Интерактивная градуировка не получает данные

## Симптом

На MIC-200 после запуска сбора точки мастер через секунду сообщал, что новые
отсчёты не получены либо ГХ нельзя обратить.

## Подтверждённые факты

- Мастер вызывал только `BeginCalibrationCapture`; штатный Preview не запускал.
- Буфер градуировки наполняется лишь из `TransformTagValue` при публикации
  новых данных источником.
- Журнал MIC-200 показывает остановку Preview в 13:48:11 и последующее
  сохранение настроек тега в 13:50:32 без нового запуска источников.
- Текст про обратную ГХ был ложным: `InverseTransform` мастер не вызывает.
- При отсутствующей промежуточной ГХ `TransformSampleToTargetInput` выполнял
  `Exit` с оставшимся `Result=True`.

## Критерий готовности

Нажатие «Собрать» из остановленного режима запускает Preview через
`TRecorderApplicationController`, ждёт первый отсчёт, после него собирает
полную секунду и показывает отдельную понятную причину при отказе.

## Исправление

- Реестр получил нейтральный callback запуска данных; MainForm реализует его
  через `TRecorderApplicationController.StartPreview`.
- Callback хранится в реестре, поэтому работает и для диалога из главного окна,
  и для вложенного диалога общих настроек.
- Таймер опрашивает только счётчик заранее выделенного capture-буфера: до
  первого отсчёта ждёт не более 5 секунд, затем измеряет 1 секунду.
- Отсутствующая промежуточная ГХ теперь возвращает ошибку, а диагностика
  отличает отсутствие данных от несовместимых единиц pipeline.

## Проверка

- Forced Windows `RecorderLnx.lpi` — exit 0.
- Forced Windows `RecorderTagsTest.lpi` — exit 0.
- Полная Linux-сборка — exit 0, ELF x86-64, `MISSING_LIBS=none`.
- DEB 0.1.85 установлен только на MIC-200; приложение устойчиво запущено в
  пользовательском systemd-сеансе, PID 9440, MC-201 подготовлены.
- Ограничение: автоматического средства нажатия кнопки в удалённой GTK-сессии
  MIC-200 нет; фактический UI-сбор подтверждается следующим стендовым нажатием.

## Дополнение: единицы эталона и завершение Preview

- Диалог показывает итоговую `UnitOut` и разрешает выбрать только совместимую
  единицу эталона. До построения множителя или прямой обе эталонные точки
  переводятся в `UnitOut`; например, `1 g` становится `9,80665 m/s2`.
- Для коррекции последнего узла используется его `UnitOut`; для сквозной ГХ —
  итоговая единица тега.
- Callback запуска возвращает признак владения Preview. Если Preview был
  запущен мастером, он останавливается при OK, Cancel или ошибке; между точками
  двухточечной градуировки остаётся запущенным. Чужой Preview/Record не
  останавливается.
- CoreServices-тест подтверждает `g <-> m/s2`; forced Windows и Linux сборки
  завершились успешно. Версия 0.1.88 установлена на MIC-200.
