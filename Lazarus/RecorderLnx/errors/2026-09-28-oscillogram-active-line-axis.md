# Панель осциллограммы управляла не осью активной линии

## Симптом

После выбора линии на другой Y-оси линия становилась активной визуально, но
поля «Масштаб Y» и «Смещение Y» продолжали работать с первой осью.

## Причина

Индекс активной серии использовался для легенды и отрисовки поверх остальных,
а обработчики панели жёстко читали `fAxis` и свойства первой оси компонента.

## Исправление

По активной серии определяется назначенная ей ось. Панель читает viewport и
модель этой оси, а ввод масштаба, смещения и spin изменяют только её
`YScale/YOffset`. Линии на одной оси разделяют одни параметры.

## Проверка

Forced Windows build — exit code 0. Linux build — `BUILD_EXIT=0`,
`MISSING_LIBS none`. RecorderLnx 0.1.93 установлен на MIC-200.
