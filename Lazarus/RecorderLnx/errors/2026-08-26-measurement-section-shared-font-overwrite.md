# 2026-08-26 — размер шрифта сечения откатывался

## Симптом

После изменения размера шрифта, нажатия «Отформатировать все» и `OK` внешний
вид компонентов сечения не менялся.

## Причина

Заголовок и механические напряжения ссылались на одно имя шрифта. Диалог хранил
два локальных снимка: сначала записывал новый снимок заголовка в менеджер, затем
под тем же именем записывал старый снимок напряжений и откатывал изменение.

## Исправление

- При редактировании одного из двух полей одинакового именованного шрифта второй
  локальный снимок синхронизируется с ним.
- При подтверждении одно имя определяется в менеджере только один раз.
- Массовое назначение по-прежнему выполняется после `OK`.

## Проверка

Forced Windows build с отдельным незаблокированным именем executable — exit 0.
Штатный `RecorderLnx.exe` был занят запущенным экземпляром программы.

## Правило

Одно имя в менеджере соответствует одному определению шрифта. Диалог с
несколькими ролями одного имени обязан синхронизировать черновики и записывать
это имя ровно один раз.
