# 2026-08-27 — OGL-осциллограмма уезжает за длину окна по X

## Симптом

При окне осциллограммы 1 сек пользователь может прокрутить/сдвинуть масштаб X
так, что справа появляется пустая область за концом осциллограммы, например
диапазон `0.4..1.4`.

## Проверенные факты

- Компонент мнемосхемы реализован в `TRecorderOglOscillogram`.
- Базовая страница использует отдельную обертку `TRecorderOglOscillogramSurface`.
- В обоих путях при пользовательском `ZoomedX=True` старый код не ограничивал
  `XMinValue/XMaxValue`.
- В обоих `Refresh` есть ранний выход, если данные не изменились, поэтому
  ограничение надо проверять до этого выхода.

## Сделано

- Добавлен общий helper `ClampOscillogramPageX`.
- Диапазон X ограничивается интервалом `0..ADisplaySeconds`.
- Если пользователь раздвинул окно шире полной длины, вид сбрасывается на
  полный интервал.
- Кламп вызывается до раннего выхода по неизменившимся данным и перед
  заполнением трендов.

## Ожидаемый эффект

При прокрутке/панорамировании по X видимое окно не должно уходить левее нуля и
правее длины отображаемой осциллограммы.
