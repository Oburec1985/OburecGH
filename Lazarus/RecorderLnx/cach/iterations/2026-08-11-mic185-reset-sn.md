# MIC-185: после сброса читается SN, но настройка не завершается

## Запрос

После сброса у MIC-185 появился серийный номер. Проверить, означает ли это
восстановление связи, и исправить неполный сброс.

## Результат

- По журналу разделены этапы: чтение паспорта прошло, `SN=162`, но настройка
  завершилась ошибкой `ProgramDeviceBin: 8BAC07D9`.
- Код `8BAC07D9` расшифрован по `meerrors.h`: это штатный `E_MEB_TIMEOUT`, а не
  ошибка разбора ответа.
- Найден регресс: всем TCP-клиентам назначался общий `id_from`. Оригинальный
  `CTCPLink` передаёт уникальный идентификатор экземпляра клиента, по которому
  прибор адресует ответ.
- Восстановлен уникальный 32-битный `id_from` для каждого TCP-клиента.
- Полная сборка RecorderLnx для Windows прошла.

## Проверить на стенде

После сброса этап `configure` должен завершиться успешно. Затем нужен прогон
сбора данных дольше трёх минут.
