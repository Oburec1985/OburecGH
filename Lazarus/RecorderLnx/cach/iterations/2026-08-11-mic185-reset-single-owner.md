# 2026-08-11 — один владелец переподключения при сбросе

**Запрос:** ручной сброс должен восстанавливать неподключившиеся приборы так же
надёжно, как повторный запуск оригинального Recorder.

**Сделано:** удалён временный клиент, который программировал MIC-185 перед
штатным источником. Сброс теперь освобождает сессию и ставит запрос, после чего
обычный источник один раз выполняет `Connect/Initialize/Configure`. Результат
оценивается после подготовки по состоянию источника.

**Проверка:** полная сборка `RecorderLnx.lpi` прошла успешно.

**Статус:** код готов; нужна проверка сброса одного недоступного MIC-185.
