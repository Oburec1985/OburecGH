# MIC-185: общий reset повторяет отказавшие устройства

## Запрос

Исправить ситуацию, когда MIC-185 до ручного сброса показывался зелёным, а
после сброса становился красным. Сверить одиночный и общий reset с оригинальным
Recorder.

## Что выяснено

- В журнале `192.168.9.155` не прошёл чтение версии и серийного номера ещё при
  запуске. Зелёный цвет позже выставлялся простым TCP probe и был ложным.
- Одиночный reset оригинала делает один проход.
- Общий reset оригинала повторно сбрасывает только устройства, которые не
  восстановились с первого прохода.

## Что сделано

- Протокольная ошибка больше не снимается простым TCP probe без живой сессии.
- Для общего reset добавлен второй проход только по оставшимся offline
  источникам. Одиночный reset оставлен однопроходным.
- В lifecycle-журнал добавлена стадия `reset-retry`.

## Проверка

Исходники полностью скомпилированы. Финальная линковка не выполнена: запущенный
экземпляр `RecorderLnx.exe` удерживает целевой файл (`error code 5`). После
закрытия приложения требуется повторить полную сборку и проверить общий reset
на стенде.
