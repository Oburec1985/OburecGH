# Итерация: восстановление init MIC-185

**Запрос:** изучить свежий lifecycle-лог и устранить ситуацию, когда TCP-порт
прибора открывается, но `GetSoftVersion` завершается IoControl timeout.

**Сделано:** подтверждено, что 150-мс stagger недостаточен. По оригинальному
`CTCPLink` восстановлен обязательный `shutdown(SD_BOTH)` перед закрытием сокета.
В `TryInitializeSession` добавлена одна локальная восстановительная попытка с
новой TCP-сессией после 250 мс. Повтор относится только к init,
конфигурирование остаётся отдельной многократно вызываемой стадией.

**Проверка:** `lazbuild -B RecorderLnx.lpi`, exit code 0; EXE слинкован.

**Осталось:** холодный стендовый запуск и анализ нового `[MIC185-LC]` лога.
