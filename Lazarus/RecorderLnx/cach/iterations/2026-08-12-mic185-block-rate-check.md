# MIC-185: проверка темпа логических блоков

## Запрос

Проверить число корректных блоков после общего reset при периоде данных 200 мс
и зафиксировать общий критерий проверки драйверов.

## Результат

На отметке около 20 секунд ожидается `20 / 0,2 = 100` блоков. Пять MIC-185
дали 96, 100, 100, 101 и 101 блок. У всех `buffered=0`, `syncdrop=0`,
`lost=False`. Фактический темп соответствует пяти блокам в секунду; число
TCP-пакетов не равно числу логических блоков.

В skill `device-lifecycle-programming` добавлен инвариант `N = T / P` и правило
считать блоки отдельно для каждого устройства.
