remote installation/payload verification — passed.

**Статус:** готово; дальнейший деплой запускается одним BAT.

## 2026-10-09 — отдельный BAT для включения SSH на Windows-стенде

**Запрос:** сделать самостоятельный BAT для переноса на флешке, без включения
в установщик RecorderLnx.

**Сделано:** в корне репозитория создан `enable-openssh-server.bat`; он
устанавливает штатный OpenSSH Server, проверяет конфигурацию, включает `sshd`,
создаёт правило TCP/22 для локальной подсети и выполняет локальный тест порта.
Пароли не принимает и не сохраняет; installer и его staging не изменяются.

**Проверка:** статическая проверка команд и ветвей ошибок; живой запуск требует
локального запуска от администратора на целевом Windows ПК.

**Статус:** готов для копирования на флешку.

**Исправление после первой попытки:** порт 22 на `192.168.15.84` остался
закрыт. Устранено ошибочное `^|` внутри уже заключённых в кавычки PowerShell
команд, добавлен постоянный `enable-openssh-server.log` рядом с BAT и его копия
в `C:\Mera Files\screens`, если каталог существует. PowerShell-фрагменты
проверены встроенным parser API; повторный живой запуск ещё требуется.

Скриншот `C:\Mera Files\screens\err.png` подтвердил root cause: старая версия
передала `^` в `Get-WindowsCapability`, поэтому capability не проверялась.
Исправленный файл с совпавшим SHA-256 скопирован на стенд как
`C:\Mera Files\screens\enable-openssh-server-v2.bat`.

## 2026-10-09 — Проверка диапазона MIC-185 после отвязки TagSettingsDialog

- Запрос: проверить, не сломалось ли переключение аппаратного диапазона MIC-185 после переноса аппаратной логики из общего диалога настройки тега; на 3Е130 оригинальный Recorder работает на 500 мВ, RecorderLnx показывает зашкал.
- Проверено: активная конфигурация KIP3, журнал программирования MIC-185, бинарная раскладка `CMIC185V2_BASECHAN_SETTINGS`, номера диапазонов и реализация оригинального драйвера.
- Результат: диапазон 500 мВ корректно кодируется как `range=0` и доходит до `ProgramDeviceBin`; общий `TagSettingsDialog` аппаратный диапазон не меняет. Обнаружено, что окно настройки MIC-185 при текущем множественном выделении применяет выбранные параметры ко всем 64 каналам. В 14:53 диапазон источника .159 был повторно изменён с 500 мВ на 5 мВ (`range=2`) для всех 64 каналов.
- Осталось: при следующем запуске на 500 мВ снять сырой код АЦП и пересчитанное значение 3Е130, чтобы однозначно разделить неприменившийся аппаратный диапазон и ошибку программного преобразования/индикации зашкала.
