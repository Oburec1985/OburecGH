## 2026-10-13 — защита захваченного кадра триггера и проверка legacy ABI

Пользователь сообщил, что кадр по спаду успевает появиться, но затем его
заменяет буфер без события. Перевёл минимальный интервал повторного захвата с
zoom-окна на полную настроенную длительность кадра и очищаю его при изменении

принимается плагином по старому префиксу: `DoEvent` читается/записывается

Forced-сборки RecorderLnx, SampleInfoPlugin и SamplePluginProbe прошли; тест
FormModel и ABI probe прошли. Runtime-проверка физического захвата ожидает
операторского сигнала. Полная самодостаточность плагина не заявляется:
legacy host не предоставляет API для plugin-owned UI/event-обработки и сам
содержит UI-логику осциллографа; требуется уточнить целевой старый host.
