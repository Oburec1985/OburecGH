# Автономный эталон MIC-140

Этот проект является зафиксированным стендом протокола MIC-140. Он не должен
использовать исходники, бинарные модули или ресурсы из рабочего RecorderLnx и
SharedUtils.

## Контракт автономности

- Все прикладные Pascal-юниты находятся в этом каталоге.
- `OtherUnitFiles` содержит только локальные пути `device/...`.
- Результаты чистой сборки находятся в `lib_standalone`, чтобы старые PPU из
  других проектов не маскировали отсутствующие зависимости.
- Лог создаётся рядом с exe.
- Изменение драйвера RecorderLnx не должно менять поведение или сборку стенда.
- Перенос всего каталога в произвольную папку и `lazbuild -B
  Mic140ProtocolDebug_Codex.lpi` обязаны завершаться успешно.

Источником восстановленных протокольных юнитов послужил срез
`D:\works\bu\recorder_lnx\010\RecorderLnx\_buildverify\Device\MIC140v2`.
Локальные совместимые контракты также зафиксированы в `device`.

Нельзя заменять эти локальные файлы ссылками на текущие реализации RecorderLnx:
так эталон незаметно меняется вместе с основным проектом и перестаёт позволять
определить, в какой момент был повреждён протокол.
