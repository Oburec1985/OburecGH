# Histogram (68 frames captured): size_words=163 ONLY
#
#   MDP header: SYNC=0x12B8 PORT=0 SIZE=163 HCS DCS
#   Payload layout:
#     [0..9]   BIOS header (10 words)
#     [10..60] sample row 0: 51 words = AIn1..48 + TIn1..3
#     [61..111] sample row 1
#     [112..162] sample row 2
#
#   dataWords = 153 = 3 × stride(51)
#   msgWords  = 163 = 10 + 153
#   fifoReady (implicit) = 153 words data per MDP packet
#
# Recorder НЕ использует stride=48 / msgWords=106.

# 3. СВОДНАЯ ТАБЛИЦА ПРОТОКОЛА
# =============================================================================
#
# | Параметр          | Recorder (дамп) | Стенд fifo=48 | Стенд fifo=51 |
# |-------------------|-----------------|---------------|---------------|
# | PORT=0 SIZE words | 163             | 106           | 112           |
# | BIOS header       | 10              | 10            | 10            |
# | dataWords         | 153             | 96            | 102           |
# | stride            | 51              | 48            | 51            |
# | samples/packet    | 3               | 2             | 2             |
# | fifoReady         | 153 (3×51)      | 96  (2×48)    | 102 (2×51)    |
# | TIn в FIFO        | да [48..50]     | нет (DM)      | нет (мусор)   |
# | CH01..24          | OK              | OK            | OK (head)     |
# | CH25..48          | OK-ish live     | FAIL          | FAIL          |
#
# Вывод: Recorder программирует FIFO stride=51 и отдаёт 3 строки×51 слово за MDP-кадр.
# Стенд по умолчанию (fifo=48) расходится по формату кадра и по CH25+.
# fifo=51 приближает stride, но ready=102 и TIn-ptr (MASK) всё ещё не дают эталонный кадр.

# =============================================================================
# 4. ПРОГРАММИРОВАНИЕ (PORT=1) — Recorder CMD samples
# =============================================================================
#
# CMD 111 (0x6F) WRITE_DM — типичный кадр size=35 words:
#   [0]=0x006F [1]=0x0020 [2]=0x0001 [3]=0x4862 [4]=0x4041 ...
#   (32 data words + 3 header — запись в DM page/addr)
#
# CMD 0x98 size=9  — служебный (identify / setup)
# CMD 0x51 size=3  — короткий ACK-подобный
# CMD 0x50 size=3  — stop-related
#
# Полный разбор scan descriptor (fifo ready=153, chanDump, ptr list) из PORT=1
# требует реконструкции последовательности WRITE_DM → отдельный проход по ETL.
