# Техническое задание: ClearBladeDB

В каталоге `Lazarus Tests` сделать проект `ClearBladeDB`, который выполняет следующее:
1. Рекурсивно обходит каталоги, начиная с указанного пути (например, `"c:\Mera Files\bladeMdb\"`).
2. Объект БД — это когда имя папки совпадает с именем xml-файла на том же уровне.
3. Иерархия:
   - Первый уровень: турбина (Turbine)
   - Второй уровень: ступень (Stage)
   - Третий уровень: лопатка (Blade)
4. В папке с лопатками лежат `*.xls` и `*.mera` файлы.
5. Сделать клинер, который удаляет все турбины с подкаталогами, если в папках с лопатками нет `*.mera` файлов и нет `*.*xls*` (все виды excel) файлов.
