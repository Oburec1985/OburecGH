# Заметки по проекту ClearBladeDB

## История промптов и изменений
- **2026-07-22 16:41**: Первоначальный запрос. Создать в `Lazarus Tests` проект `ClearBladeDB`.
  - *Суть*: Рекурсивный обход базы данных (турбина -> ступень -> лопатка). Удалять турбины без `.mera` и без `*.xls*` файлов в лопатках.
  - *Правила кодировки*: Lazarus-файлы сохранять в cp1251, CRLF, без BOM. Использовать `CP1251ToUTF8` для LCL-компонентов.
- **2026-07-22 17:06**: Уточнение требований. 
  - *Суть*: Если турбина сохраняется, но в ней есть пустые ступени (у которых во всех лопатках нет полезных файлов), эти ступени нужно удалить (каталог ступени + xml-файл ступени на уровне турбины).
  - *Решение*: Перейти на иерархическую модель данных.

## Архитектурные решения
1. **Иерархическая структура**:
   - `TBladeInfo`: лопатка (путь к каталогу, XML, количество файлов).
   - `TStageInfo`: ступень (путь к каталогу, XML, список лопаток, признак `HasUsefulFiles`).
   - `TTurbineInfo`: турбина (путь к каталогу, XML, список ступеней, признак `HasUsefulFiles`).
2. **Логика удаления**:
   - Если `Turbine.HasUsefulFiles = False`, удаляем всю турбину (каталог турбины и файл `Turbine.xml` на уровне корня).
   - Если `Turbine.HasUsefulFiles = True`, обходим `Turbine.Stages`:
     - Если `Stage.HasUsefulFiles = False`, удаляем ступень (каталог ступени и файл `Stage.xml` внутри папки турбины).
