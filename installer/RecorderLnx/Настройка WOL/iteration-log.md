# Журнал настройки Wake-on-LAN

## 2026-09-11 17:25 — массовая настройка WOL

**Запрос:** создать BAT, который читает список Linux-хостов с паролями и
включает Wake-on-LAN командой `ethtool -s enp3s0 wol g` на каждом ПК.

**Сделано:** добавлен массовый SSH-скрипт с настройкой и проверкой `Wake-on: g`;
создаётся включённый systemd-сервис для восстановления WOL после перезагрузки.
Ошибки одного узла не прерывают обработку остальных, в конце выводится итог.

**Проверка:** dry-run обработал все четыре записи без SSH-подключений: четыре
успешных результата, ошибок нет.

**Статус:** готово; фактический запуск изменит настройки удалённых ПК.
