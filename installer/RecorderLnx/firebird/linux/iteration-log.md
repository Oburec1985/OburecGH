# Журнал итераций Firebird и RCPanel installer

## 2026-09-11 17:45 — ошибка после ввода пароля остаётся на экране

**Запрос:** после первого запроса административного пароля установка не должна
мгновенно закрываться вместо продолжения.

**Сделано:** `pkexec` запускает абсолютные `/bin/bash` и путь установщика без
зависимости от очищенного окружения и рабочего каталога. Исходный пользователь
передаётся аргументом. При неудаче окно остаётся открытым и показывает код и
путь `/tmp/recorderlnx-firebird-install.log`.

**Проверка:** `bash -n install-firebird-recorderlnx.sh` — exit code 0;
проверка реального `pkexec` требуется на Linux.

**Статус:** готово к повторной проверке установки.

## 2026-09-11 16:55 — установка запускается за один клик

**Запрос:** устранить необходимость закрывать консоль после запроса прав и
повторно запускать установщик Firebird+RCPanel.

**Сделано:** GUI-запуск после выбора компонентов повышает права через `pkexec`
и продолжает тот же процесс; для консольного режима сохранён `sudo`. Имя
исходного пользователя передаётся для установки его ярлыка rcPanel.

**Проверка:** структура ветвей и аргументы повторного запуска проверены;
локальный `bash` для syntax-check в Windows отсутствует.

**Статус:** готово к проверке одним запуском на Linux.
