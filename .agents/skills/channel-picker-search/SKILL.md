# Поиск в выборе каналов

Во всяком интерфейсе, где пользователь добавляет или выбирает канал/тег из
списка, делай видимое поле поиска по подстроке. Это относится к настройкам
компонентов, алгоритмов, графиков, источников и пакетному выбору каналов.

## Контракт

- Фильтруй без учёта регистра как минимум по имени, адресу и описанию.
- Обновляй список сразу при изменении строки поиска; пустая строка возвращает
  полный допустимый список.
- Сначала применяй предметный фильтр допустимости, затем текстовый поиск.
  Поиск не должен возвращать запрещённые для данного контекста теги.
- Храни identity отдельно от отображаемого текста: связывай строку со
  стабильными `TagId` и настоящим `TagName`. Частоту, единицу и пояснения можно
  добавлять только в caption; нельзя восстанавливать identity разбором caption
  или старым индексом списка.
- После фильтрации сохраняй выделение того же identity, если он ещё видим.
  При выборе новой строки синхронно записывай и ID, и имя.
- Компоновка должна работать в Windows и Linux при другом DPI и шрифте: поле
  поиска закреплено сверху, прокручиваемый список занимает оставшееся место,
  кнопки не перекрывают список.
- Для длинных списков подготовь записи один раз, а при вводе перестраивай
  только видимое представление.

## Проверка

Проверь поиск по фрагменту из середины имени, адресу, описанию и смешанному
регистру; очистку фильтра; выбор после фильтрации; повторное открытие диалога;
отсутствие подмены выбранного тега первым или ранее выбранным элементом.
