# Context7 Sources

Use these Context7 libraries while applying the Lazarus skills:

- `/fpc/fpcdocumentation` for Free Pascal units, classes, SysUtils, Classes, streams, exceptions, memory, strings, and TThread.
- `/marsupilami79/zeoslib` for ZeosLib database components, TZConnection, TZQuery, transactions, and DBC layer.
- `/viniciussanchez/restrequest4delphi` for RESTRequest4Delphi fluent HTTP clients and adapters.
- `/salvadordf/cef4delphi` for embedding Chromium in Delphi/Lazarus/FPC apps with CEF4Delphi.

Context7 did not expose a high-quality primary Lazarus/LCL documentation library in this session. For LCL-specific APIs, inspect the local project and installed Lazarus sources first, then use web/official Lazarus docs if necessary.
